# 寻址方式

| 寻址方式      | 说明                              |
| :-------- | :------------------------------ |
| 立即寻址      | 操作数嵌入在指令中                       |
| 寄存器直接寻址   | 操作数位于 CPU 的寄存器中                 |
| 寄存器间接寻址   | 寄存器中的值作为指针                      |
| 基址寻址/变址寻址 | 一个基址加一个偏移量                      |
| 相对寻址      | 基址寻址的特例，计数器 PC 作为基址寄存器，一般用于跳转指令 |
| 堆栈寻址      | 通过堆栈指针寄存器来管理数据存取                |

# MIPS 指令系统

## MIPS寄存器结构

| 组件 | 说明 |
| :--- | :--- |
| 地址空间 | 32 位虚拟地址空间 |
| GPRs | 32 个 32 位通用寄存器 |
| FPRs | 32 个 32 位浮点数寄存器 |
| HI、LO | 乘除寄存器 |
| PC | 程序计数器 |

## MIPS 寄存器使用约定

| 寄存器名 | 编号 | 用途 |
| :--- | :--- | :--- |
| `zero` | 0 | 值恒为 0 |
| `at` | 1 | 为汇编程序保留 |
| `v0` - `v1` | 2-3 | 过程调用返回值 |
| `a0` - `a3` | 4-7 | 过程调用参数 |
| `t0` - `t7` | 8-15 | 临时变量（调用者保存） |
| `s0` - `s7` | 16-23 | 保存寄存器（被调用者保存） |
| `t8` - `t9` | 24-25 | 其他临时变量 |
| `k0` - `k1` | 26-27 | 为操作系统保留 |
| `gp` | 28 | 全局指针 |
| `sp` | 29 | 栈指针 |
| `fp` | 30 | 帧指针 |
| `ra` | 31 | 过程调用返回地址 |

## MIPS 指令分类

| 指令类型 | 说明 |
| :--- | :--- |
| R 型指令 | 两个寄存器操作数，计算结果给第三个寄存器 |
| I 型指令 | 使用 1 个带符号 16 位立即数参与计算 |
| J 型指令 | 跳转指令，26 位跳转地址 |

## 指令字段布局

### R 型指令

Op 固定为 0，由 Func 告知运算的种类。

| 指令类型  | 6 bits | 5 bits | 5 bits | 5 bits | 5 bits | 6 bits |
| :---- | :----- | ------ | ------ | ------ | ------ | ------ |
| R 型指令 | Op     | Rs     | Rt     | Rd     | Shamt  | Func   |

### I 型指令

用 16 位立即数进行寻址，或直接利用立即数计算。

| 指令类型  | 6 bits | 5 bits | 5 bits | 16 bits   |
| :---- | :----- | ------ | ------ | --------- |
| I 型指令 | Op     | Rs     | Rt     | Immediate |

### J 型指令

用 26 位立即数进行寻址。

| 指令类型  | 6 bits | 26 bits   |
| :---- | :----- | --------- |
| J 型指令 | Op     | Immediate |

## MIPS 寻址方式

| 指令类型  | 支持的寻址方式                                     |
| :---- | :------------------------------------------ |
| R 型指令 | 寄存器寻址                                       |
| I 型指令 | 立即数寻址、基址寻址（以 PC 为基址）、寄存器间接寻址（`rs + offset`） |
| J 型指令 | 绝对寻址                                        |

# MIPS 常用指令【!】

## R 型指令

| 指令     | 格式                  | 说明                 | 注意             |
| :----- | :------------------ | ------------------ | -------------- |
| `add`  | `add rd, rs, rt`    | rd ← （rs） + （rt）   | 无 shamt        |
| `sll`  | `sll rd, rt, shamt` | rd ← （rt） << shamt | 逻辑左移           |
| `sllv` | `sllv rd, rt, rs`   | rd ← （rt） << (rs)  | 左移的值是寄存器内容     |
| `slt`  | `slt rd, rs, rt`    | rd ← (rs < rt)     | 比较             |
| `jr`   | `jr rs`             | PC ← （rs）          | 寄存器跳转，因此不是 J 型 |

##  I 型指令

| 指令     | 格式                       | 说明                          |
| :----- | :----------------------- | --------------------------- |
| `addi` | `addi rt, rs, immediate` | 带有立即数的运算/逻辑运算               |
| `lw`   | `lw rt, offset(base)`    | rt ← memory\[base + offset] |
| `sw`   | `sw rt, offset(base)`    | memory\[base + offset] ← rt |
| `beq`  | `beq rs, rt, offset`     | 分支跳转指令                      |

## J 型指令

| 指令    | 格式           |
| :---- | :----------- |
| `j`   | `j target`   |
| `jal` | `jal target` |
