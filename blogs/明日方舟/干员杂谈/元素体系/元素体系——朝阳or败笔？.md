# 概述

元素体系自 2023 年 7 月才开始在我方阵营中实装。作为一个新兴的机制体系，目前已经广泛存在于很多新干员或模组之中。

不幸的是，不同元素损伤之间会**互相抢条**，这就导致具有不同损伤类型的干员往往不能进行合作，甚至会有帮倒忙的情况。

虽然在设计师看来，这样能够使得编队特化、在不同关卡中合理选择不同体系，但事实是除了元素损伤和元素伤害外，元素体系的各个干员或多或少都有其他的亮眼表现，导致不同元素体系的角色强度大相径庭，甚至还没等来队友就惨遭淘汰。

那么，设计师的设计初衷到底如何？各体系的强度又如何？让我们仔细分析。

## 元素体系的优势区间

由于当前环境下暂时没有任何损伤抗性或元素抗性的敌人，因此元素伤害可以看作是另一种真伤。

### 日常

在日常环境下，我们大概率见不到极高防御或极高法抗的敌人，即使有，m3 才是更好的真伤选择，我们其实根本就不会刚需元素体系，或者说只是想娱乐或加速的时候才会考虑使用。

### 肉鸽

另外，由于元素爆条产生的伤害是固定值，我们很难让爆条手在肉鸽中打出可观的伤害；如果要在抓位中加入对应的元素 C，往往会显得臃肿或耗费希望。

再者，在肉鸽的技力回转的不确定性下，我们也不容易让爆条手和元素 C 同时开启技能。因此纵观各大肉鸽的核心抓位，目前没有任何元素体系。
### 合约

但环境到了危机合约，就开始发生转机了。首先，元素伤害能够无视防御和法抗，只要危机合约不是每次都是高额全伤害减伤，而是猛猛加防加抗的话，元素伤害将是最容易造成伤害的方法。

由此观之，元素体系像是危机合约特化式的体系，在最近的几次危机合约中，各大元素体系都有出现，这恰恰证明了设计师的设计思路是没有问题的。

## 元素体系的职业分支

### 爆条手：巫役、本源铁卫

注意看巫役和本源铁卫的特性描述，可以造成**元素损伤**，而并未说明可以造成**元素伤害**。

由此观之，巫役和本源铁卫的全部职责就是爆条，并不管伤害的事情。

### 元素 C：本源术师、本源近卫

本源术师和本源近卫的特性描述是：可以造成**元素伤害**。

所以不要再争吵为什么本源术师的三技能都不能独立爆条，这本来就是设计师的思路罢了。

而且注意看，本源术师即使可以造成元素损伤，也是基于造成伤害的比例结算的。对于低法抗敌人，根本无需爆条；对于高法抗敌人，又根本打不出损伤。这么看来，设计师明显就是让元素 C 和爆条手高度绑定。

这种设计思路其实并没有任何问题，毕竟体系队强绑定是很多游戏的常见套路。但问题在于，明日方舟不一样，各个干员的强度差异比较明显，而且攻击范围、技能回转和部署位置都是会对整体布局和出伤造成极大影响的因素。你无法保证爆条手和元素 C 每次都能部署在绝佳的位置进行配合、每次都能够同时开大、每次都能完美攻击到同一个敌人。

是的，这样一分析，其实元素体系的问题还是挺大的。那么设计师到底具体是怎么设计干员的，有没有解决这些看似左右脑互搏的问题呢？

# 凋亡体系

## 效果设计

凋亡损伤爆条能够造成持续的元素伤害，且让敌人获得虚弱效果，15 s 恢复时间。

作为第一个应用在我方的元素损伤效果，凋亡损伤或许是吃了早出的亏，毒点很明显。

### 持续伤害

持续伤害明显没有爆发伤害好。对于爆条手而言，在爆发期间也无法造成伤害，为什么不在爆条瞬间就打出伤害呢？对于元素 C 而言，有可能本来 12000 点元素伤害可以秒杀的敌人，由于一开始并没有死亡，导致浪费了一次攻击。

### 虚弱

看上去这个虚弱是一个很不错的控制效果，按理来说可以保人，但事实并非如此。首先，虚弱的最大值仅有 50%，并没有明显减少敌方攻击力，在大部分情况下其实并没有太大区别；其次，这个虚弱还会随时间慢慢减弱效果。本来在爆条期间敌人也就攻击不了几次，还让虚弱效果慢慢降低，实战中也不好对轴，综合下来其实这个虚弱名存实亡，几乎没有实战价值。

### 长恢复时间

设计师的思路是让恢复时间延长，好让元素 C 抓紧时间输出。但实际上，这会导致爆条手单走能力大大下降，而且 5 s 的延时对本源术师的输出其实影响并不大，远远不如快速恢复快速爆条的总伤来得高。

## 干员设计

### 爆条手

作为第一个六星巫役，塑心的设计完美诠释了爆条手的设计理念。一技能单体高速爆条、二技能爆条输出两手抓、三技能大范围集体爆条。但问题也同样出在这里：除了爆条以外几乎没有任何作用！那么塑心只可能和凋亡大 C 配合。如果凋亡大 C 自身够强，那么塑心可有可无；如果大 C 较弱，那么根本无法上场。对于强绑体系和站位的干员来说，1+1>2 其实是远远不够的，至少要 1+1>3 才有可能有一定的上场概率。

### 元素 C

目前凋亡的元素 C 主要有两个：逻各斯和妮芙。对于逻各斯，自身在日常已经够强，完全不需要塑心也基本可以快速爆条，到了合约，对生存和站位都会严格限制，与其臃肿地带上逻各斯和塑心，远远不如一个 mon3tr 来得方便；对于妮芙，本身范围和总伤都不出色的情况下，只有二技能的恐惧可能在危机合约有上场空间，但这就与元素体系毫无关系了。

综上所述，凋亡体系或许是亏在出太早，也或许是设计师根本没有考虑过配合并不只是纸面上的理想情况，整体来看是比较失败的。他们光荣地完成了自己的义务，但并没有履行他们应该弥补设计漏洞的责任。

# 灼燃体系

## 效果设计

灼燃损伤爆条能够降低敌方 20 点法抗，持续 10 s。

### 降低法抗

这是一个非常有意义的词条。首先，目前爆条手主要是本源术师，这样不仅能够吃到附带的元素伤害，而且还能吃到法术伤害的拐。其次，降低法抗使得灼燃爆条手并不绑定本源术师或其他元素 C，而是几乎所有法伤干员，只不过哪个相性好哪个不好罢了。

### 短恢复时间

这其实有利有弊。利在由于爆条伤害不算高，反复爆条可以增加爆条手单走的伤害；弊在如果爆条手不给力或没有对好轴，元素 C 会亏伤害。

## 干员设计

### 爆条手

灼燃的爆条手很有意思，是用余的一道火墙这一特殊机制进行爆条的。这有一个很严重的问题：术师的手不够长怎么办？术师的攻击频率不够怎么办？这就导致了余的三技能非常考验队友的相性。

但设计师这次学聪明了，既然配合是很麻烦的事情，那就加强单走能力！于是余的二技能华丽出现，单走能力极强，不仅是个非常合格的盾，而且输出完全不逊色，还有传送的机制，让阻挡爆条的天赋体现地淋漓尽致。

新出的模组更是非常逻辑自洽，二技能和三技能都有相当不错的提升，设计师对余的设计真的无法挑剔。

### 元素 C

灼燃的元素 C 更是十分有趣，正统元素 C 不在本源术师而在御械！可以说是荒芜拉普兰德的巨大售后，在日常关卡中可以达到 1+1>>2 的效果，说达到 4 甚至 5 个人的水平都不为过。不仅技能时间和回转相差无几，机制上也是完美匹配：穿过火墙与打全图、高频次爆条与御械的高 hit、降法抗与无法穿... 设计师完美解决了拉普兰德和余三技能的所有痛点！

而本源术师烛煌，相比拉普兰德起来根本难以匹及，反而成为余拉体系的一个拐了。增加爆条瞬间伤害其实对余拉的日常提升是相当可观的。不过，除去挂件功能之外，煌的强度其实并不算高，因此在各大模式的排名都很尴尬。

综上所述，灼燃体系是一个设计非常完善且自洽的体系，不仅爆条手和元素 C （这里指拉普兰德）的自身强度都不错，而且互相配合轻松、提升巨大，完全找不到任何可以喷的地方啊！设计师你做的好啊！

# 神经体系

## 效果设计

神经损伤爆条会施加 3 层麻痹，持续 10 s。

### 麻痹

这是一个非常伟大的机制。巫役和本源术师自身是没有生存能力的，而施加麻痹则可以通过削弱敌人，变相提高生存能力。凋亡损伤的虚弱要掉小珍珠了 QAQ。

### 持续时间

说实话，这个持续时间虽然较短，但还真不能说它短了。毕竟如果爆条频率加快，麻痹能够反复施加，这可比前两个体系的单纯输出来得实在。

## 干员设计

### 爆条手

强度膨胀的顶峰——酒神粉墨登场！酒神不仅有着和塑心相当的爆条能力，还比塑心多了最重要的东西——控制！

众所周知，危机合约仅从输出角度来看已经超过了 13 个干员的输出上限了，唯一能够解决的只有控制。酒神之前，歌蕾蒂娅、温蒂、妮芙、莫斯提马、麦哲伦这些老牌控制干员之所以能上场，都是因为有独特的控制恰巧能派上用场。但酒神杀死了比赛。酒神的控制兼具位置控制和攻击控制，一个干员能做好几个干员的事情。

但我曾经有过一个疑惑：酒神三技能让爆条恢复时间缩短至 5 s，真的不会导致元素 C 亏伤害吗？

### 元素 C

真言的诞生消除了我所有疑虑，不得不佩服设计师的小巧思。

真言是通过麻痹溢出层数造成伤害的！我之前从来没有跳脱出元素体系的常规设计思路，完全没有想过还能这样计算伤害。这一机制使得真言同样不用依赖爆条手也可以输出！另外，真言的大范围反隐也能让酒神的牢笼困住更多敌人。

但是真言的问题依旧存在，例如，如果没有酒神，元素伤害是有上限的，一旦造成麻痹的次数用光，后续的输出能力较为一般，因此基本还是要绑定酒神才可上场。好在酒神足够强力，如果巫役只是像塑心一样，估计真言也会视为强度抑制的产物吧。

综上所述，神经体系也是足够机制自洽的，但 80%的强度都集中在酒神自身，且酒神 50%的强度并不来源于神经损伤。因此，设计师又找到了另一条路来发展元素体系，即构建一超多强的干员格局，使得神经损伤不会重蹈凋亡的覆辙。

# 展望

元素体系经历过凋亡的设计牺牲后，慢慢找到了正确的方向，经常给人眼前一亮的设计。目前三大元素体系已经较为完善，虽然依然有发展空间，但我猜想后续很可能会开辟侵蚀损伤这一新路径。

如果侵蚀损伤在我方实装，效果可能是爆条期间防御力下降，那么元素 C 大概率就是本源近卫或新出一个本源狙击的分支。假日威龙陈或许很适合这一体系。如果为其装配 delta 模组，或许能有不错的提升。但如果侵蚀损伤真是降低防御力，那么爆条手用巫役必然不合适，期待设计师会带来什么样的惊喜呢？

我认为元素体系绝不是一个败笔，而是朝阳升起。无论后续出现元素紊乱打出合体技，还是保持当前的设计思路给各个体系补强，我觉得都是未来可期。
