# 并查集基础

#### 并查集是一个数据结构，用于快速判断一个无向图中，两个顶点是否连通。

## 初始化并查集（init）

并查集的第一个基本操作当然是先初始化！

我们假设现在要判断一群信类的新生是否属于同一个书院。那我们必须要让每一个人提供自己的“上司”（其实叫做 parent），即普通学生提供自己的小班长，小班长提供大班长，大班长提供书院名。

但如果只是这样，会出现什么问题吗？试想一下，假如你用程序一直寻找这个人的上司，直到寻找书院的上司，发现找不到！然后很有可能就面临 RE 的局面。

因此我们决定这样做：

#### 初始设置每个顶点的 parent 是它自己。

## 寻找上司（find）

我们必须要知道自己的上司是谁，这样才能通过逐层缩小来知道自己和另一个人到底是不是同一个部门的。

我们的最终目的是找到最高层的上司，因为同一个部门的人可能中间几级的上司不同，但最终 boss 一定是一个人！

于是我们很自然地就想到了递归。既然想到了递归，那不可避免的就需要思考两个问题：

### 1. 终止递归的条件是什么？

根据我们初始化的逻辑，最高级上司的上司应该就是他自己。因此我们可以通过这个条件判断我们是不是找到了最高级上司。

核心代码：

```cpp
int find(int x)
{
	if (parent[x] == x)
	{
		return x;
	}
	// other codes...
}
```

### 2. 未终止时需要做些什么？

在基础的并查集操作里面，这个问题很简单。如果还不是最高级上司，那么继续找上司就好了。

核心代码：

```cpp
int find(int x)
{
	// other codes...
	return find(parent[x]);
}
```

## 合并集合（unite）

在建造并查集时，我们需要通过加上关系（即边）来使得一个新的节点加入这个集合。具体怎么做呢？

其实，要让一个新入职的人加入你们的团队，只需要将这个人的最终上司（我们叫 root）挂到你们最终上司的名下即可。**我的老板的附庸的附庸，是我的同事！**

核心代码：

```cpp
void unite(int x, int y)
{
	int rootX = find(x);
	int rootY = find(y);
	if (rootX != rootY)
	{
		parent[rootY] = rootX;
	}
}
```

至此，并查集的基本操作就结束了！

但……真的就结束了吗？

# 并查集优化

信类每年招 1000 多个学生，要想知道两个人是否属于同一书院，我们得要让每一个人都先找小班长，再找大班长，再找书院。那如果分得更细呢？比如再分小组长，小队长……那么每次询问都得要递归好几次！

## 按秩合并

我们为了减少上司的层数以减少 find 的递归次数，我们必须要保证以最终上司为根的这棵树深度尽量地少。可以采用如下操作：

#### 将深度小的树接在深度大的树根处

这样一来，如果两个树深度（即秩）不相等时，合并后的树深度不会超过大的那一棵！即使两个树深度相等，最终也只是加 1 层深度。

核心代码：(当然，在初始化时，需要初始化每个单节点的秩为 0)

```cpp
void unite(int x, int y)
{
	int rootX = find(x);
	int rootY = find(y);
	if (rootX == rootY)
	{
		return;
	}
	
	if (rank[rootX] < rank[rootY])
	{
		parent[rootX] = rootY;
	}
	else if (rank[rootX] > rootY)
	{
		parent[rootY] = rootX;
	}
	else
	{
		parent[rootY] = rootX;
		rank[rootX]++;
	}
}
```

## 路径压缩

不过，即使是按秩合并了，也难以保证最终深度不会很大。

难道，我们只能记住自己的小班长吗？我们为什么不能**直接记住自己的书院**呢？这样别人只要问我是什么书院的，再跟他的比较，不就直接比出来是不是一个书院了吗？

很聪明的想法！我们只需要让小班长把大班长告诉我，再让大班长把书院名告诉我，不就可以直接知道书院名了吗！

因此，我们可以在 find 过程中直接添加这种功能，**让自己的 parent 直接变为 root**！

核心代码：

```cpp
int find(int x)
{
	if (parent[x] != x)
	{
		parent[x] = find(parent[x]);
	}
	return parent[x];
}
```

这样一来，我们就可以在 find 的过程中顺手记住自己的最高级上司了！

### 函数形式

int rankTree[MAXN];

void init(int n) {

### 封装为类

```cpp
class UnionFind
{
private:
    vector<int> parent;
    vector<int> rank;
    int n; // 节点数量

public:
    // 构造函数
    UnionFind(int size)
    {
        n = size;
        parent.resize(n + 1); // 为了从1开始编号
        rank.resize(n + 1, 0);
        init();
    }

    // 初始化
    void init()
    {
        for (int i = 1; i <= n; i++)
        {
            parent[i] = i;
            rank[i] = 0;
        }
    }

    // 查找根节点（带路径压缩）
    int find(int x)
    {
        if (parent[x] != x)
        {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }

    // 合并两个集合（按秩合并）
    void unite(int x, int y)
    {
        int rootX = find(x);
        int rootY = find(y);
        if (rootX == rootY)
        {
            return;
        }

        // 按秩合并
        if (rank[rootX] < rank[rootY])
        {
            parent[rootX] = rootY;
        }
        else if (rank[rootX] > rank[rootY])
        {
            parent[rootY] = rootX;
        }
        else
        {
            parent[rootY] = rootX;
            rank[rootX]++;
        }
    }

    // 检查两个节点是否在同一集合
    bool isConnected(int x, int y)
    {
        return find(x) == find(y);
    }

    // 获取连通分量数量
    int getCount()
    {
        int count = 0;
        for (int i = 1; i <= n; i++)
        {
            if (parent[i] == i)
            {
                count++;
            }
        }
        return count;
    }
};
```

# 并查集的应用

## 检测图中是否有环

什么时候一个无向图中会有环呢？我们可以这样想：加入目前的图是一个无环的图。那么如何添加一条边让这个无环的图变得有环呢？

添加一条边有两种可能：

1. 连接两个本来就不连通的点。但这样很显然是无法形成环的。
2. 连接两个本来就处于同一个连通分量的点。诶，这样似乎就成环了。

连通分量，这不正是并查集做的事吗！没错，如果两个点的 root 相同，那么这两个点就是处于同一个连通分量之中；反之则不是。

因此我们就很容易想到了：当新加入的边的两个顶点 root 已经相同，那么新加的这条边就会使图中成环！

代码也很好改，我们只需要在 unite 操作中略施小计，让 unite 函数有返回值，当 rootX == rootY 时返回一个 flag 值，表示这次 unite 让图成环了！

---

说到检测是否有环，那么不得不想到 Kruskal 算法。是的，Kruskal 算法就是并查集的一个典型应用！

## Kruskal 算法

简单来说，Kruskal 算法就是尽量选择最小权重的边，但要保证不成环。

人能够轻易看出来是否成环，而机器则不一定！有了并查集之后，最复杂的判断的时间复杂度居然被缩减到了近似 O（1）！伟大的发明！

```cpp
int kruskal(int n, vector<Edge> &edges)
{
    // 1. 初始化并查集
    UnionFind uf(n);

    // 2. 对边按权重排序
    sort(edges.begin(), edges.end());

    // 3. 依次处理边
    int mstWeight = 0; // 最小生成树的总权重
    int edgesUsed = 0; // 已使用的边数

    for (const Edge &edge : edges)
    {
        // 如果加入这条边不会形成环
        if (uf.unite(edge.u, edge.v))
        {
            mstWeight += edge.weight;
            edgesUsed++;

            // 已经找到n-1条边，形成最小生成树
            if (edgesUsed == n - 1)
            {
                break;
            }
        }
    }

    // 如果图不连通，可能edgesUsed < n-1
    if (edgesUsed < n - 1)
    {
        cout << "图不连通，无法生成最小生成树" << endl;
        return -1;
    }

    return mstWeight;
}
```

# 例题练习

## 带属性统计的并查集

### 题目
 
> **题目描述**
> 
> 幻想乡的大陆由 $n$ 座城市和 $m$ 条城市间的双向道路组成，并不保证所有城市连通。第 $i$ 座城市都有一块种类为 $w_i$ 的冰块（$1 \leq w_i \leq 9$）。
> 
> 冰之勇者琪露诺会从一个城市出发，然后沿道路去往不同的城市，每到一个城市，她都会收集城市中的冰块（包含初始城市的冰块）。现在她想知道她从哪些城市出发可以集齐 $9$ 种冰块（即收集到种类 $1$ 到 $9$ 的所有冰块）。
> 
> 你只需要告诉她有多少个这样的城市即可。
> 
> **输入格式**
> 
> 第一行两个整数 $n, m$ $(1 \leq n, m \leq 2 \times 10^5)$。  
> 第二行 $n$ 个整数，第 $i$ 个整数表示第 $i$ 座城市的冰块种类 $w_i$。  
> 接下来 $m$ 行，每行两个整数 $u, v$，表示城市 $u$ 和 $v$ 之间有一条道路。
> 
> **输出格式**
> 
> 输出一个整数，表示满足条件的起始城市数量。
> 
> **样例输入**
> 
> ```
> 5 4
> 1 2 3 4 5
> 1 2
> 2 3
> 3 4
> 4 5
> ```
> 
> **样例输出**
> 
> ```
> 0
> ```
> 
> (注：此样例中无法集齐 9 种，因为只有 1-5 种)

### 思路分析

#### 为什么想到并查集？

因为这是个**无向图连通性问题**。在一个连通分量中，勇者可以走到所有的城市中，获取所有城市中的冰块。

#### 如何利用并查集进行统计？

由于我们会将一整个连通分量交给并查集的 root 来代表，因此我们可以考虑在 root 中存储整个连通分量中所有包含的冰块种类。

那么什么时候传递信息到 root 呢？我们不难想到，在 unite 操作的时候，就是把自己挂到 root 下的时候，那我们为什么不在这个地方进行传递呢？

于是我们可以稍微修改一下 unite 函数，使之可以**顺手**将自己的冰块传给自己的 parent 的 root。

为了传递信息，我们可以定义一个 bool 类型的二维数组 has，用于记录某一个城市是否拥有某一个冰块。（注意，我们需要**传递冰块**，所以一个城市是可以超过一个冰块的。当一个城市在合并中丧失了 root 的身份时，以这个城市为第一维的 has 数组的这部分就名存实亡了。）

```cpp
void unite(int x, int y)
{
    int rootX = find(x);
    int rootY = find(y);

    if (rootX != rootY)
    {
        parent[rootY] = rootX;

        // 合并种类信息：把rootY的所有种类加到rootX
        for (int k = 1; k <= 9; k++)
        {
            if (has[rootY][k])
            {
                has[rootX][k] = true;
            }
        }
    }
}
```

其实到这里，题目的核心代码就已经完成了。除去输入部分，最终我们只需要按照要求输出答案即可。

题目要求输出所有符合要求的城市数量，而不是连通块数量。那么如何输出城市数量呢？其实也很简单。由于我们所有的信息都是储存在 root 里的，那么我们就需要 find 每一个节点的 root，看 root 是否同时拥有了所有冰块即可！

以下是 AC 代码：

```cpp
#include <algorithm>
#include <cstring>
#include <iostream>
#include <unordered_map>

using namespace std;
typedef long long ll;

#define MAXN 200005

int parent[MAXN];
int rankTree[MAXN];

bool has[MAXN][10];

void init(int n)
{
    for (int i = 1; i <= n; i++)
    {
        parent[i] = i;
        rankTree[i] = 0;
    }
}

int find(int x)
{
    if (parent[x] != x)
    {
        parent[x] = find(parent[x]);
    }
    return parent[x];
}

void passIce(int rootY, int rootX)
{
    // 合并种类信息：把rootY的所有种类加到rootX
    for (int k = 1; k <= 9; k++)
    {
        if (has[rootY][k])
        {
            has[rootX][k] = true;
        }
    }
}

void unite(int x, int y)
{
    int rootX = find(x);
    int rootY = find(y);

    if (rootX == rootY)
    {
        return;
    }

    if (rankTree[rootX] < rankTree[rootY])
    {
        parent[rootX] = rootY;
        passIce(rootX, rootY);
    }
    else if (rankTree[rootX] > rankTree[rootY])
    {
        parent[rootY] = rootX;
        passIce(rootY, rootX);
    }
    else
    {
        parent[rootY] = rootX;
        passIce(rootY, rootX);
        rankTree[rootX]++;
    }
}

int main()
{
    int n, m;
    cin >> n >> m;
    // 初始化并查集
    init(n);
    // 读入每个城市的冰块种类
    for (int i = 1; i <= n; i++)
    {
        int iceType;
        cin >> iceType;
        has[i][iceType] = true;
    }
    // 读入道路信息并合并城市
    for (int i = 0; i < m; i++)
    {
        int u, v;
        cin >> u >> v;
        unite(u, v);
    }

    int ans = 0;
    for (int i = 1; i <= n; i++)
    {
        int rootI = find(i);
        int flag = 1;
        for (int k = 1; k <= 9; k++)
        {
            if (!has[rootI][k])
            {
                flag = 0;
                break;
            }
        }
        if (flag)
        {
            ans++;
        }
    }
    cout << ans << endl;
    return 0;
}
```
