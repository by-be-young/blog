# MIPS【!】

占比约 15%

## CISC 与 RISC

CISC （如x86）中指令较多，一条指令可以干多种事情，但由于指令长度不固定，难以流水化。

RISC （如 MIPS）中指令较少，但指令长度固定，适合流水化，让硬件更简单

## MIPS 指令实现

#### 由于 R 型指令的立即数只有 16 位，为了加载 32 位的立即数，往往使用 lui 指令（Load Upper Immediate）

> **例题：** 用不超过两条指令从内存地址为 0xF78C000C 的单元读取一个字到寄存器 $t0 当中。
> 
> [answer]
> 
> 解：
> 
> 取字需要用 lw 指令；对于 32 位立即数往往采用 lui 和 ori 加载到寄存器。
> 
> 为了保证不超过两条指令，我们需要优化 ori。
> 
> 注意到 lw 指令中隐含加法功能，而 ori 其实也是一种加法的表现。故可以将 ori 与 lw 融合。
> 
> lui $t0 0xF78C
> 
> lw \$t0 0x000C(\$t0)
> 
> [\answer]

## 主存储器

### 结构

容量表示为：字单元数 × 每个字单元的位数，即 $2^n \times m$。

#### 需要 $n$ 条地址线（寻址 $2^n$ 个字单元），$m$ 条数据线（每个字单元 $m$ 位）。

#### 总存储位数 = 行数 × 列数 = $2^r+2^c=2^{r+c}$；

#### 需要 r 根行地址线、$2^r$ 根行选择线。

### 扩展

位扩展：将多片芯片并联；字扩展：将多片芯片串联。

### DRAM 刷新

#### 分布式（异步）刷新方式下，刷新周期等于最大刷新间隔。

#### $刷新地址计数器位数=\frac{log_2{存储单元数}}{2}$。

## Cache

### 主存地址结构

#### 【主存行号（m 位）|偏移量（b 位）】

或表示为【Tag 位（m-c 位）|组索引位（c 位）|偏移量（b 位）】

### Cache 块结构

#### 【Tag 位|有效位|（一致位）|（替换算法位）|数据位】

或表示为【数据映射表|数据】

## VM

### 物理地址结构

又称实地址。

#### 【实页号|页内偏移】

### 虚拟地址结构

又称虚地址、逻辑地址。

#### 【虚页号|页内偏移】，其中页内偏移与物理地址位数相同。

或表示为【Tag|组索引|页内偏移】

### TLB 行结构

#### 【Tag|有效位|（一致位）|实页号】

# 总线与 IO

占比约 5%

| 周期名称              | 核心定义与角色                           | 关键特点                                        |
| :---------------- | :-------------------------------- | :------------------------------------------ |
| **时钟周期**          | CPU 主时钟的振荡周期，**最基础的时间单位**。        | 由 CPU 主频决定，是所有同步操作的计时基准。                    |
| **总线周期**          | CPU 通过系统总线与内存/I/O 进行一次完整数据交换所需时间。 | 包含地址、数据、控制信号的完整传输时序，是**系统通信的基本单元**。         |
| **机器周期 (CPU 周期)** | CPU 完成一个**基本操作阶段**（如取指令、执行运算）的时间。 | 从 CPU 功能角度划分工作阶段，是构成指令周期的功能模块。              |
| **指令周期**          | CPU 从**取指到执行完毕**一条指令所需的全部时间。      | 因指令复杂度不同而差异巨大，是衡量程序执行速度的宏观单位。               |
| **存储周期**          | **存储器**进行一次完整读写操作所需的最小时间间隔。       | **是 DMA 与总线访问的物理瓶颈**，通常包括**存取时间**和**恢复时间**。 |

**时间尺度**：时钟周期 < 总线周期 ≤ 存储周期 ≤ 机器周期 < 指令周期。
