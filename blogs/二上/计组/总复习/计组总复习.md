# MIPS【!】

占比约 15%

## CISC 与 RISC

CISC （如x86）中指令较多，一条指令可以干多种事情，但由于指令长度不固定，难以流水化。

RISC （如 MIPS）中指令较少，但指令长度固定，适合流水化，让硬件更简单

## MIPS 指令实现

#### 由于 R 型指令的立即数只有 16 位，为了加载 32 位的立即数，往往使用 lui 指令（Load Upper Immediate）

[task]
[question]
用不超过两条指令从内存地址为 0 xF 78 C 000 C 的单元读取一个字到寄存器 $t 0 当中。
[\question]
[answer]
```
lui $t0 0xF78C
lw $t0 0x000C($t0)
```
[\answer]
[analysis]
取字需要用 lw 指令；对于 32 位立即数往往采用 lui 和 ori 加载到寄存器。

为了保证不超过两条指令，我们需要优化 ori。

注意到 lw 指令中隐含加法功能，而 ori 其实也是一种加法的表现。故可以将 ori 与 lw 融合。

Lui 指令将高 16 位立即数加载到寄存器高位，低 16 位清零，得到 0 xF 78 C 0000。

Lw 指令的偏移量字段为 16 位有符号数，0 x 000 C 作为偏移量与基址寄存器 $t 0 相加，得到完整地址 0 xF 78 C 000 C，完成取数操作。
[\analysis]

占比约 30%。

特别注意按字节编址与按字编址的区别。通常 1 字=4 字节。

## 主存储器

### 结构

容量表示为：字单元数 × 每个字单元的位数，即 $2^n \times m$。

#### 需要 $n$ 条地址线（寻址 $2^n$ 个字单元），$m$ 条数据线（每个字单元 $m$ 位）。

#### 总存储位数 = 行数 × 列数 = $2^r+2^c=2^{r+c}$；

#### 需要 r 根行地址线、$2^r$ 根行选择线。

### 扩展

位扩展：将多片芯片并联；字扩展：将多片芯片串联。

### DRAM 刷新

#### 分布式（异步）刷新方式下，刷新周期等于最大刷新间隔。

#### $刷新地址计数器位数=\frac{log_2{存储单元数}}{2}$。

# 链接与运行

占比约 10%

## 符号分类（按链接可见性）

| 类别 | 定义 | C 语言中的常见形式 | 链接特性 |
| :--- | :--- | :--- | :--- |
| **全局符号** | 在本模块中定义，并且可以被其他模块引用的符号。 | 定义在所有函数外且未被 `static` 修饰的变量或函数。<br>例如：`int global_var;` `void func() {}` | 其名称会被放入目标文件的符号表（`.symtab`）中，链接器在链接其他模块时可见。 |
| **外部符号** | 在其他模块中定义，在本模块中被引用的符号。 | 使用 `extern` 关键字声明的变量或函数（声明而非定义）。<br>例如：`extern int external_var;` `extern void ext_func();` | 本模块记录了一个未解析的引用，链接时需要在其他模块的全局符号中找到其定义。 |
| **局部符号** | 仅在本模块中定义和引用的符号，对其他模块不可见。 | 被 `static` 关键字修饰的全局变量或函数。<br>例如：`static int static_var;` `static void helper() {}` | 链接器对其不可见，不会参与全局符号解析，因此不同模块中可以存在同名的局部符号而不冲突。 |

## 符号分类（按链接器处理优先级）【!】

| 类别 | 定义 | 常见例子 | 链接器处理规则 |
| :--- | :--- | :--- | :--- |
| **强符号** | 函数名和已初始化的全局变量。 | 函数定义：`void func() {}`<br>已初始化的全局变量：`int strong_var = 10;` | 1. 不允许存在多个同名的强符号（链接错误：多重定义）。<br>2. 在符号解析时，优先级高于弱符号。 |
| **弱符号** | 未初始化的全局变量（或通过 `__attribute__((weak))` 等特性显式声明为弱的符号）。 | 未初始化的全局变量：`int weak_var;`<br>弱声明函数：`__attribute__((weak)) void weak_func();` | 1. 允许存在多个同名的弱符号。<br>2. 当存在一个同名的强符号时，链接器会选择强符号。<br>3. 若只有多个弱符号，链接器通常会选择其中占用空间最大的一个（具体行为可能因编译器和链接脚本而异）。 |

# 总线与 IO

占比约 5%

| 周期名称              | 核心定义与角色                           | 关键特点                                        |
| :---------------- | :-------------------------------- | :------------------------------------------ |
| **时钟周期**          | CPU 主时钟的振荡周期，**最基础的时间单位**。        | 由 CPU 主频决定，是所有同步操作的计时基准。                    |
| **总线周期**          | CPU 通过系统总线与内存/I/O 进行一次完整数据交换所需时间。 | 包含地址、数据、控制信号的完整传输时序，是**系统通信的基本单元**。         |
| **机器周期 (CPU 周期)** | CPU 完成一个**基本操作阶段**（如取指令、执行运算）的时间。 | 从 CPU 功能角度划分工作阶段，是构成指令周期的功能模块。              |
| **指令周期**          | CPU 从**取指到执行完毕**一条指令所需的全部时间。      | 因指令复杂度不同而差异巨大，是衡量程序执行速度的宏观单位。               |
| **存储周期**          | **存储器**进行一次完整读写操作所需的最小时间间隔。       | **是 DMA 与总线访问的物理瓶颈**，通常包括**存取时间**和**恢复时间**。 |

**时间尺度**：时钟周期 < 总线周期 ≤ 存储周期 ≤ 机器周期 < 指令周期。
