# I/O 设备的分类

## 按传输速度分类

1. 低俗设备；
2. 中速设备；
3. 高速设备。

## 按数据组织分类

1. **块设备**：以数据块为单位存储、传输信息。传输速率较高、可寻址；
2. **字符设备**：以字符为单位存储、传输信息。传输速率较低、不可寻址。

磁盘以数据块为单位进行读写（通常为 512 字节、4 KB 等），支持随机访问，属于**块设备**。字符设备以字节流为单位顺序读写，不支持随机访问，如键盘、鼠标、串口等。因此磁盘是块设备。[\analysis]
[\task]

## 按用途分类

1. 存储设备：磁盘、磁带等；
2. 传输设备：网卡、Modem 等；
3. 人机交互器：键盘、鼠标、显示器等。

## 从资源分配角度分类

1. 独占设备：在一段时间内只能由一个进程使用的设备；
2. 共享设备：在一段时间内允许多个进程共同使用的设备；
3. 虚设备：用一类设备模拟另一类设备。

# I/O 控制器

## I/O 控制器的组成

### 与 CPU 的接口

用于实现 CPU 与控制器的通信。该类接口有三种信号线：数据线（传送读写数据）、地址线（要访问 IO 接口中的寄存器编号）、控制线（传送读写等控制信号）。

### 与设备的接口

一个设备控制器通常能够与多个设备相联，因此通常有多个与设备的接口。设备接口可传输数据、控制和状态三种信号。

### IO 逻辑

用于实现 CPU 对于 IO 设备的控制，通过一组控制线与 CPU 进行交互，对从 CPU 收到的指令进行译码。

设备控制器有以下几个主要功能：接收和识别 CPU 命令、进行数据交换（包括 CPU 与控制器、控制器与设备之间）、设备状态的了解和报告、设备地址识别、数据缓冲。

## 寄存器

可以被 CPU 直接访问的**寄存器**，主要有：

1. 数据寄存器：缓存从**设备发送**来的输入数据或 **CPU 发送**来的输出数据；
2. 状态寄存器：保存设备的执行结果或状态，供 CPU **读取**；
3. 控制寄存器：由 CPU **写入**，用于启动命令或更改设备模式。

# I/O 控制方式

## 程序直接控制方式

又称“轮询方式、程序查询方式”，CPU 主动不断地检查外设状态是否准备好。在设备较少、交互不频繁的场景下实现简单，但会占用大量 CPU 时间，效率较低。

## 中断驱动方式

外设准备就绪后向 CPU 发出中断信号，CPU 暂停当前任务处理 I/O 操作，相比轮询更高效。适用于响应及时性要求较高的系统，能够显著降低 CPU 的无效等待。

## DMA 方式

即“直接内存访问”，在数据量大、频繁传输的场景中尤为高效。CPU 只负责启动 DMA 控制器，数据传输过程由 DMA 独立完成，显著提高系统整体效率。

## 通道控制方式

由专门的 I/O 通道（可视为专用处理器）管理 I/O 操作，CPU 干预程度最低，只需发出 I/O 指令即可。

# I/O 软件层次结构

## 用户层软件

产生 I/O 请求、格式化 I/O、SPOOLing 等。

如：记事本、下载按钮、上传按钮、文本编辑器等。

## 设备独立性软件

也称设备无关性软件，指应用程序所用设备不局限于某个具体的物理设备。

1. 执行所有设备的公有操作；
2. 向用户层或文件层提供统一接口。

如：缓冲与高速缓存、系统调用、逻辑设备到驱动的映射、互斥锁等。

## 设备驱动程序

与硬件直接相关，每类设备需要配置一个设备驱动程序。

如：驱动 I/O 设备工作的、用于接受上层发来的 I/O 要求、控制 I/O 设备工作、设置寄存器等。

## 中断处理程序

当 I/O 操作完成时，设备控制器发送一个中断信号，CPU 响应中断后，根据中断类型号找到相应的中断处理程序进行处理。

[question]
关于 I/O 软件错误的是：
[\question]
[options]A 设置网卡的寄存器在驱动层[\options]
[options]B I/O 格式化技术属于用户层[\options]
[options]C 缓冲机制属于设备无关软件层[\options]
[options]D 检查用户是否允许使用设备在用户层[\options]
[answer]D[\answer]
[analysis]
- 选项 A 正确：设备驱动层负责直接操作硬件寄存器，包括设置网卡寄存器。
- 选项 B 正确：I/O 格式化（如磁盘格式化）通常由用户层实用程序（如 `mkfs`）发起，属于用户层软件。
- 选项 C 正确：缓冲机制（如缓冲区高速缓存）属于设备无关软件层，为不同设备提供统一的缓冲管理。
- 选项 D **错误**：检查用户是否允许使用设备属于**设备无关软件层**（或操作系统的安全/权限管理模块）的职责，而非用户层。用户层程序无法直接检查自身权限，需通过系统调用由内核进行权限验证。[\analysis]
[\task]

[question]
关于 I/O 软件错误的是_ 。
[\question]
[options]A 为磁盘读操作计算磁道、扇区、磁头在驱动层[\options]
[options]B 假脱机技术属于设备无关软件层[\options]
[options]C 缓冲机制属于设备无关软件层[\options]
[options]D 错误报告属于设备无关软件层[\options]
[answer]B[\answer]
[analysis]
- 选项 A 正确：磁盘驱动层负责将上层抽象的读请求转换为具体的物理参数（磁道、扇区、磁头），直接操作硬件。
- 选项 B **错误**：假脱机技术（SPOOLing，Simultaneous Peripheral Operation On Line，即外部设备联机并行操作）属于**用户层软件**（或系统服务层），而非设备无关软件层。它通过在磁盘上创建输入/输出井，实现设备的虚拟化，但本身不属于内核中的设备无关软件。
- 选项 C 正确：缓冲机制（如缓冲区高速缓存）属于设备无关软件层，为不同设备提供统一的数据缓冲管理，与具体设备类型无关。
- 选项 D 正确：错误报告机制（如 I/O 错误向上层传递和处理）属于设备无关软件层，由操作系统统一处理并报告给用户或应用程序。[\analysis]
