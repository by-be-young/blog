### 问题 1：kernel. Lds - 代码段应该从哪个地址开始？

**问题描述**：
链接脚本 `kernel.lds` 中需要填写代码段的起始地址。

**代码位置**：
```ld
SECTIONS {
    /* Step 1: Set the loading address of the text section */
    . = ?????;           /* ← 这里需要填地址 */
}
```

**分析问题**：
- CPU 上电后会跳转到固定地址取第一条指令
- 如果代码放错地方，CPU 找不到 → 操作系统无法启动
- 地址信息藏在 `include/mmu.h` 的内存布局图中

**查看 mmu. H 的图**：
```c
/*
  o      KSTACKTOP-----> +----------------------------+----|-------0x8040 0000
  o                      |       Kernel Stack         |
  o      KERNBASE -----> +----------------------------+----|-------0x8002 0000
  o                      |       Kernel Text          |
*/
```

**答案**：
```ld
. = 0x80020000;
```

**为什么**：
- 图中 `KERNBASE` 箭头指向 `0x80020000`
- `KERNBASE` = 内核代码起始地址
- 0 x 80000000 到 0 x 80020000 的 128 KB 留给异常处理代码

**意义**：
- 决定所有代码的最终地址
- CPU 从 0 x 80020000 开始执行，才能找到 `_start`
- 如果填错（比如 0），操作系统无法启动

### 问题 2：kernel. Lds - 代码段里放什么？

**问题描述**：
需要定义 `.text` 段，告诉链接器把什么内容放进去。

**代码位置**：
```ld
/* Step 2: Define the text section */
.text : { ????? }        /* ← 这里需要填内容 */
```

**分析问题**：
- 每个 `.c` 文件编译后都有 `.text` 节（存放代码）
- 链接时需要把所有 `.text` 节收集到一起，形成连续的代码段

**答案**：
```ld
.text : { *(.text) }
```

**为什么**：
| 语法 | 含义 |
|------|------|
| `.text` | 定义一个叫 .text 的段 |
| `:` | 开始描述这个段 |
| `{ }` | 里面放这个段的内容 |
| `*(.text)` | `*` = 所有文件，`.text` = 这些文件中的 .text 节 |

**意义**：
- 把分散在 `init.o`、`kern/*.o`、`lib/*.o` 中的代码合并成一段
- 保证代码在内存中是连续的，CPU 能顺序执行

### 问题 3：kernel. Lds - 数据段里放什么？

**问题描述**：
需要定义 `.data` 段，收集已初始化的全局变量。

**代码位置**：
```ld
/* Step 3: Define the data section */
.data : { ????? }        /* ← 这里需要填内容 */
```

**分析问题**：
- 已初始化的全局变量（如 `int x = 5;`）放在 `.data` 节
- 这些变量有初始值，需要在 ELF 文件中保存

**答案**：
```ld
.data : { *(.data) }
```

**为什么**：
- 紧跟代码段（位置计数器自动指向代码段结束）
- 收集所有文件的 `.data` 节

**意义**：
- 保证 `int x = 5;` 这样的变量在运行时是 5，不是垃圾值

### 问题 4：kernel. Lds - BSS 段里放什么？

**问题描述**：
需要定义 `.bss` 段，并记录起止位置供启动代码清零。

**代码位置**：
```ld
bss_start = .;
/* Step 4: Define the bss section */
.bss : { ????? }
bss_end = .;
```

**分析问题**：
- 未初始化的全局变量（如 `int y;`）放在 `.bss` 节
- C 语言规定这些变量初始值为 0
- 需要在启动时清零，所以要用 `bss_start` 和 `bss_end` 记录地址范围

**答案**：
```ld
bss_start = .;
.bss : { *(.bss) }
bss_end = .;
```

**为什么**：
| 语法 | 含义 |
|------|------|
| `bss_start = .` | 记录当前位置为 BSS 起始地址 |
| `.bss : { *(.bss) }` | 定义 BSS 段，收集所有 .bss 节 |
| `bss_end = .` | 记录 BSS 结束地址 |

**意义**：
- 启动代码（start. S）用这两个地址来清空 BSS
- 保证 `int y;` 的初始值是 0

### 问题 5：start. S - 栈指针应该设成什么值？

**问题描述**：
启动代码中需要设置栈指针 `sp`，C 语言才能运行。

**代码位置**：
```asm
clear_bss_done:
    mtc0    zero, CP0_STATUS    /* 关中断 */
    /* set up the kernel stack */
    la      sp, ?????           /* ← 这里需要填地址 */
```

**分析问题**：
- C 语言需要栈来存放局部变量和函数调用
- 栈必须放在不会和代码/数据重叠的地方
- 地址信息在 `include/mmu.h` 的图中

**查看 mmu. H 的图**：
```c
/*
  o      KSTACKTOP-----> +----------------------------+----|-------0x8040 0000
  o                      |       Kernel Stack         |
*/
```

**答案**：
```asm
la      sp, 0x80400000
```

**为什么**：
- 图中 `KSTACKTOP` 箭头指向 `0x80400000`
- 栈从高地址向下增长
- 代码在 `0x80020000`，栈在 `0x80400000`，中间有 3.9 MB 空间

**意义**：
- 不设栈 → C 语言无法运行（局部变量无处存放）
- 设错地址 → 栈和代码重叠，压栈时覆盖代码，程序崩溃

### 问题 6：start. S - 如何进入 C 语言？

**问题描述**：
准备工作做完后，需要跳转到 C 语言的入口函数。

**代码位置**：
```asm
    /* jump to mips_init */
    ?????   mips_init           /* ← 这里需要填指令 */
```

**分析问题**：
- 内核主函数在 `init/init.c` 中定义为 `mips_init()`
- 需要从汇编跳转到这个函数

**答案**：
```asm
j       mips_init
```

**为什么**：
- `j` = jump，跳转到指定地址
- `mips_init` 是函数名，链接后会变成地址
- 用 `j` 不用 `jal`，因为 `mips_init` 不会返回

**意义**：
- 从汇编世界进入 C 语言世界
- 操作系统正式开始运行 C 代码

### 问题 7：print. C - 如何扫描并输出普通字符？

**问题描述**：
`vprintfmt` 函数需要扫描格式字符串，普通字符直接输出。

**代码位置**：
```c
/* scan for the next '%' */
/* Exercise 1.4: Your code here. (1/8) */
```

**分析问题**：
- 格式字符串如 `"Hello %d"` 中，`"Hello "` 是普通字符
- 遇到 `%` 才需要特殊处理
- 普通字符应该直接调用 `out` 输出

**答案**：
```c
while (*fmt != '%' && *fmt != '\0') {
    out(data, fmt, 1);
    fmt++;
}
```

**为什么**：
| 条件 | 含义 |
|------|------|
| `*fmt != '%'` | 不是格式开始符 |
| `*fmt != '\0'` | 字符串还没结束 |
| `out(data, fmt, 1)` | 输出当前字符 |
| `fmt++` | 移到下一个字符 |

**意义**：
- 让 `printk("Hello")` 能直接输出 "Hello"

### 问题 10：print. C - 如何解析格式标志？

**问题描述**：
格式说明符可能包含标志 `-`（左对齐）和 `0`（零填充）。

**代码位置**：
```c
/* check format flag */
/* Exercise 1.4: Your code here. (5/8) */
```

**分析问题**：
- `%-5d`：`-` 表示左对齐
- `%05d`：`0` 表示用 0 填充
- 需要记录这些标志，供后续输出使用

**答案**：
```c
ladjust = 0;
padc = ' ';
if (*fmt == '-') {
    ladjust = 1;
    fmt++;
}
if (*fmt == '0') {
    padc = '0';
    fmt++;
}
```

**为什么**：
| 标志 | 作用 | 记录变量 |
|------|------|----------|
| `-` | 左对齐 | `ladjust = 1` |
| `0` | 零填充 | `padc = '0'` |

**意义**：
- 让 `%-5d`（左对齐）和 `%05d`（零填充）能正确工作

### 问题 11：print. C - 如何解析宽度？

**问题描述**：
格式说明符可能包含宽度数字，如 `%10d`。

**代码位置**：
```c
/* get width */
/* Exercise 1.4: Your code here. (6/8) */
```

**分析问题**：
- `%10d` 中的 `10` 是最小输出宽度
- 需要解析出这个数字

**答案**：
```c
width = 0;
while (*fmt >= '0' && *fmt <= '9') {
    width = width * 10 + (*fmt - '0');
    fmt++;
}
```

**为什么**：
| 步骤 | 示例 `"10"` |
|------|-------------|
| 初始 | `width = 0` |
| 读 `'1'` | `width = 0*10 + 1 = 1` |
| 读 `'0'` | `width = 1*10 + 0 = 10` |
| 结果 | `width = 10` |

**意义**：
- 让 `%10d` 能输出至少 10 个字符宽度的数字

### 问题 13：print. C - 如何处理负数（%d）？

**问题描述**：
`%d` 需要输出有符号十进制数，负数需要加负号。

**代码位置**：
```c
case 'd':
case 'D':
    if (long_flag) {
        num = va_arg(ap, long int);
    } else {
        num = va_arg(ap, int);
    }
    /* Exercise 1.4: Your code here. (8/8) */
    print_num(out, data, num, 10, neg_flag, width, ladjust, padc, 0);
    break;
```

**分析问题**：
- 负数在内存中是补码，直接当正数打印会出错
- 例如 `-123` 的补码是 `0xFFFFFF85`，直接打印是 4294967173
- 需要先记负号，取绝对值，再输出

**答案**：
```c
if (num < 0) {
    neg_flag = 1;
    num = -num;
}
```

**为什么**：
| 步骤 | 示例 `-123` |
|------|-------------|
| 检测 | `num < 0` 为真 |
| 设标志 | `neg_flag = 1` |
| 取绝对值 | `num = 123` |
| 调用 print_num | 先输出 `-`，再输出 `123` |

**意义**：
- 让 `printk("%d", -123)` 输出 `-123`，而不是 `4294967173`

## 第四部分：最终答案汇总

### Kernel. Lds
```ld
SECTIONS {
    . = 0x80020000;
    .text : { *(.text) }
    .data : { *(.data) }
    bss_start = .;
    .bss : { *(.bss) }
    bss_end = .;
    . = 0x80400000;
    end = . ;
}
```

### Init/start. S（清空 BSS 后的部分）
```asm
clear_bss_done:
    mtc0    zero, CP0_STATUS
    la      sp, 0x80400000
    j       mips_init
```

### Lib/print. C（vprintfmt 中 8 个空）
```c
// (1/8) 扫描普通字符
while (*fmt != '%' && *fmt != '\0') {
    out(data, fmt, 1);
    fmt++;
}

// (3/8) 检查结束
if (*fmt == '\0') break;

// (4/8) 跳过 %
fmt++;

// (5/8) 解析标志
ladjust = 0;
padc = ' ';
if (*fmt == '-') { ladjust = 1; fmt++; }
if (*fmt == '0') { padc = '0'; fmt++; }

// (6/8) 解析宽度
width = 0;
while (*fmt >= '0' && *fmt <= '9') {
    width = width * 10 + (*fmt - '0');
    fmt++;
}

// (7/8) 解析长整型
long_flag = 0;
if (*fmt == 'l') { long_flag = 1; fmt++; }

// (8/8) 处理负数（在 case 'd' 中）
if (num < 0) {
    neg_flag = 1;
    num = -num;
}
```
