## 正则化

### L 1 正则化

$$L(w) = Loss + \lambda \|w\|_1$$

产生**稀疏解**，可以把某些权重压缩到 0。

### L 2 正则化

$$L(w) = Loss + \lambda \|w\|_2^2$$

让所有权重都变小但不会变成 0，也叫权重衰减。

**两个坑**：
- 正则化项必须和模型参数 $w$ 有关。如果写成 $\lambda Y^T Y$（只和数据有关，和 $w$ 无关），起不到正则化作用。
- $\lambda$ 必须大于 0。如果 $\lambda < 0$，变成鼓励 $w$ 增大，和正则化目标相反，起不到正则化作用。

## 线性回归

**模型**：$f(x_i) = w x_i + b$，输出是连续值。

**损失函数（平方损失）**：
$$L(w,b) = \sum_{i=1}^{n} (y_i - (wx_i + b))^2$$

**优化方法**：
- 最小二乘法：对 $w$ 和 $b$ 求偏导等于 0，直接解出答案。
- 梯度下降法：$w = w - \eta \frac{\partial L}{\partial w}$，一步步迭代。

**闭式解**：
$$w = \frac{\sum_{i=1}^{n} (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^{n} (x_i - \bar{x})^2}$$
$$b = \bar{y} - w\bar{x}$$

**注意**：$x_i$ 是单个样本值，$\bar{x}$ 是所有 $x$ 的平均值。

## 对数几率回归

**模型**：把线性回归的结果塞进 Sigmoid 函数，映射到 (0,1) 之间，表示属于类别 1 的概率。
$$\hat{y} = \frac{1}{1 + e^{-(w^T x + b)}}$$

**损失函数（交叉熵）**：
$$L(\theta) = -\sum_{i=1}^{n} [y_i \log(f_\theta(x_i)) + (1-y_i)\log(1-f_\theta(x_i))]$$

**梯度**：
$$\frac{\partial L}{\partial \theta_j} = \sum_{i=1}^{n} (f_\theta(x_i) - y_i) x_{ij}$$

梯度下降更新：$$\theta_j = \theta_j - \eta \sum_{i=1}^{n} (f_\theta(x_i) - y_i) x_{ij}$$

## Softmax 多分类

$$y_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$$

作用：把多个输出变成概率分布，所有类别概率加起来等于 1。损失函数用多分类交叉熵。

## 线性判别分析 LDA/FDA

核心思想：投影后同类尽量集中（类内方差小），不同类尽量分开（类间均值差大）。

Fisher 准则：
$$J(w) = \frac{\|m_2 - m_1\|_2^2}{s_1^2 + s_2^2}$$

## 支持向量机 SVM

核心思想：找一个超平面，让两类样本离这个平面的距离（间隔）最大。

硬间隔 SVM：
$$\min_{w,b} \frac{1}{2}\|w\|^2$$
要求：$$y_i(w^T x_i + b) \geq 1$$

软间隔 SVM（加了松弛变量，允许少量点分错）：
$$L(w) = \min_{w,b} \frac{1}{2} w^T w + C \sum_{i=1}^n \max(0, 1 - y_i(w^T x_i + b))$$

**重要概念**：支持向量是离分类超平面最近的那些样本点。只有支持向量决定了分类边界，其他点不影响。

## 决策树

**划分度量**：

| 指标 | 对应算法 | 选择准则 |
|------|----------|----------|
| 信息增益 | ID 3 | 越大越好 |
| 信息增益率 | C 4.5 | 越大越好 |
| 基尼系数 | CART | 越小越好 |

**计算公式**：

信息熵：$$H(Y) = -\sum_{k} P(Y=y_k) \log_2 P(Y=y_k)$$

条件熵：$$H(Y|a) = -\sum_{v} P(a=a^v) \sum_{k} P(Y=y_k|a=a^v) \log_2 P(Y=y_k|a=a^v)$$

信息增益：$$IG(D,a) = H(Y) - H(Y|a)$$

IV 值：$$IV(a) = -\sum_{v} P(a=a^v) \log_2 P(a=a^v)$$

信息增益率：$$GainRatio = IG / IV(a)$$

## 前馈神经网络

结构：输入层 + 至少一个隐藏层 + 输出层。层与层之间**全连接**（每个神经元都连到下一层的所有神经元）。没有反馈，数据从输入到输出单向流动。

**激活函数**：

| 函数 | 公式 | 特点 |
|------|------|------|
| Sigmoid | $$\sigma(x) = \frac{1}{1+e^{-x}}$$ | 输出在 (0,1)，两头梯度接近 0（梯度饱和） |
| ReLU | $$\max(0,x)$$ | 简单、快、缓解梯度消失 |

**参数初始化**：所有参数**不能**初始化为 0，也**不能**全部初始化为相同的值。因为同一层神经元参数相同时，反向传播收到的误差也一样，更新后参数仍相同，所有神经元学到的东西一模一样，失去意义。

## 卷积神经网络 CNN

**三层结构**：
- 卷积层：卷积核在图像上滑动，做点积运算
- 池化层：缩小尺寸（最大池化或平均池化）
- 全连接层：最后接全连接层做分类

**CNN 流程**：输入图像 → [卷积+池化] × N → 展平 → 全连接层 → Softmax 输出

## 自注意力机制 Self-Attention

**目的**：在序列里找到每个位置和其他位置的相关性，捕获全局依赖。

**QKV 计算**：

给定输入向量 $x_i$，用三个权重矩阵分别算出：
$$q_i = W^Q x_i$$$$k_i = W^K x_i$$$$v_i = W^V x_i$$

**计算步骤**：
1. 算注意力分数（点积）：$$\alpha_{ij} = q_i \cdot k_j$$再除以 $\sqrt{d_k}$（$d_k$ 是向量维度）
2. 对每一行做 Softmax：$$\hat{\alpha}_{ij} = \frac{\exp(\alpha_{ij})}{\sum_j \exp(\alpha_{ij})}$$
3. 算输出：$$o_i = \sum_j \hat{\alpha}_{ij} \cdot v_j$$

**位置编码**：Self-Attention 本身不知道位置信息，需要额外加位置编码向量 $e^i$。

# 生成式人工智能

## 主成分分析 PCA

核心思想：往方差最大的方向投影，同时让重构误差最小。这两个等价。

优化目标：
$$\min_{\{w^1,\dots,w^K\}} \sum_{i=1}^{N} \left\| (x_i - \bar{x}) - \sum_{k=1}^{K} c_{i,k} w^k \right\|_2^2$$
要求各个 $w^k$ 互相正交，且长度等于 1。

## 自编码器 vs 变分自编码器

**自编码器**：编码器把输入压缩成编码，解码器把编码还原。目标是重构误差最小。只能还原，不能生成新样本。

**变分自编码器 VAE**：编码器输出的是均值+方差（一个分布），从分布里采样得到编码，再解码。隐空间是连续的，可以插值生成新样本。

| | 自编码器 | VAE |
|--|----------|-----|
| 隐空间 | 确定的一个点 | 一个概率分布（均值+方差） |
| 目标函数 | 只有重构损失 | 重构损失 + KL 散度 |
| 能否生成 | 不能 | 能 |

**KL 散度的作用**：强迫隐空间接近标准正态分布，使编码之间连续，随便取一个点都能生成合理图像，且可以插值。

## 扩散模型

核心思想：
- 前向过程：给图像一步步加噪声，最后变成纯噪声
- 反向过程：训练神经网络学会去噪，从噪声一步步变回图像

## 生成对抗网络 GAN

结构：**生成器**（从噪声生成假图）+ **判别器**（判断真假），两者对抗训练，最终生成器能生成很真的图。


# 强化学习

## 核心概念

| 概念 | 定义 |
|------|------|
| 状态（State） | 智能体现在看到的环境信息 |
| 动作（Action） | 智能体可以做的一个操作 |
| 奖励（Reward） | 做完动作后环境给的即时反馈（可正可负） |
| 策略（Policy） | 给定状态，选择哪个动作的规则 $\pi(s) \to a$ |
| 回报（Return） | 从当前开始到结束，所有折扣奖励加总 $G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \cdots$ |
| 折扣因子（$\gamma$） | 0 到 1 之间，越接近 1 越看重未来奖励 |

## 价值函数

$V_\pi(s)$：在状态 $s$ 时，按策略 $\pi$ 走，未来能得到多少折扣奖励的期望。

$Q_\pi(s,a)$：在状态 $s$ 时，先执行动作 $a$，之后按策略 $\pi$ 走，未来能得到多少折扣奖励的期望。

**两个核心关系**：
$$V_\pi(s) = \sum_{a} \pi(s,a) \cdot Q_\pi(s,a)$$（把所有动作按概率加权）
$$Q_\pi(s,a) = \sum_{s'} P(s'|s,a) \cdot [R(s,a,s') + \gamma V_\pi(s')]$$（执行动作后可能转移到多个状态，分别算）

## 贝尔曼方程

核心思想就是递推：当前价值 = 即时奖励 + 折扣 × 下一状态价值。

$$V_\pi(s_t) = r_{t+1} + \gamma V_\pi(s_{t+1})$$

## 策略评估方法

| 方法 | 类型 | 特点 |
|------|------|------|
| 动态规划 | Model-based | 需要知道状态转移概率 |
| 蒙特卡洛 | Model-free | 跑完一整局才更新 |
| 时序差分 TD | Model-free | 每走一步就更新 |

## 策略优化

**策略优化定理**：$$\pi'(s) = \arg\max_a Q_\pi(s,a)$$。即给定当前 $Q$ 值，选 $Q$ 值最大的那个动作作为新策略。

## Q-Learning

**Q 值更新公式**：
$$Q(s,a) \leftarrow Q(s,a) + \alpha \left[ R + \gamma \max_{a'} Q(s',a') - Q(s,a) \right]$$

$\alpha$ 是学习率，$\max_{a'} Q(s',a')$ 是下一个状态里最大的 $Q$ 值。

**算法步骤**：
1. 看当前状态 $s$，根据规则选动作 $a$（一般是选 $Q$ 值最大的）
2. 执行动作，看去了哪个新状态 $s'$，得到多少奖励 $R$
3. 在新状态 $s'$ 的 $Q$ 值表里找到最大值 $\max_{a'} Q(s',a')$
4. 代入更新公式算新的 $Q(s,a)$
5. 更新策略：看每个状态里 $Q$ 值更大的动作是哪个
