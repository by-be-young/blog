# 思考题

## Thinking 1.1

> 请思考并回答，在真实的操作系统中，如果使用内存中的地址作为文件控制块的字段，会出现哪些问题？为什么我们目前的操作系统不会出现这些问题？

文件控制块是存储在磁盘中的，而磁盘是不能存储虚拟地址的。因为：

1. 虚拟地址的地址空间相互隔离，其他进程无法正确使用该虚拟地址。
2. 内存页面可能会被换出，导致原本虚拟地址失效，或者指向错误数据。
3. 操作系统重启后，内存地址空间会重新初始化，导致虚拟地址失效。
4. 如果将磁盘迁移到其他操作系统中，虚拟地址失效。

我们目前的操作系统不会进行内存页面的交换，且文件服务进程是独立的，始终保持运行，不会切换进程。同时，我们也不支持磁盘动态分配和回收，不存在地址的变更。

## Thinking 4.1

> 请自行设计一种检查地址是否已分配，并实现地址分配的方案。需要满足以下三个要求：一是可供分配的地址范围为 `[0x10000000, 0x50000000)` ；二是保证已分配的地址能够正确被回收；三是**保证较低的地址优先被分配**。在设计好分配方案后，分析该方案占用的时间和空间，并据此简述为什么选取该方案。提示：你可以回顾本学期实验课程中遇到的所有分配方案，例如页控制块和进程控制块的分配、asid 的分配、fileid 的分配、fdnum 的分配等。

采用位图法。

### 占用空间

$1GB / 4KB / 8 = 32KB$。

### 占用时间

分配一个页需要遍历所有位，时间复杂度为 O (n)，但检查是否已被分配、或者回收，都只需要 O (1)。

### 选取原因

1. 从地位向高位扫描，保证较低的地址优先被分配。
2. 空间占用小，实现简单高效。

## Thinking 4.2

> 请自行设计一种数据结构，用于存储磁盘块编号到缓存地址的映射，使得**时间复杂度最小**。注意存储并维护磁盘块编号不对应任何缓存地址的状态（即磁盘块未被缓存的状态）。

采用数组的方法一一映射。

数据结构：

```C
#define MAX_BLOCK 1024
static void *block_cache_va[MAX_BLOCK];
```

其中数组内每个元素存放对应下标的磁盘块的虚拟地址。

增删映射只需要将数组元素改成对应虚拟地址或 0 即可，时间复杂度均为 O (1)。
