# 什么是活用形

将**动词、形容词、形容动词**的词尾改变，用作不同的语法功能。

#### 体言（如名词）没有活用形。

# 六大活用形

## 动词的活用形

| 活用形 | 主要用法              |
| --- | ----------------- |
| 未然形 | 构成ない形、意向形、使役形、被动形 |
| 連用形 | 构成ます形、て形、た形；合成词   |
| 終止形 | 句子结尾（简体形）         |
| 連体形 | 连接名词（简体形）         |
| 仮定形 | 构成ば形              |
| 命令形 | 命令                |

病気になって（）、健康の大切さがわかった。  
[\question]  
[options]A はじめて[\options]

[options]C たびに[\options]  
[options]D からには[\options]  
[answer]A[\answer]  
[analysis]  
从意思的角度：

「~てはじめて」表示“在……之后才……”，意为经历了某件事之后才有了新的认识或变化。句子意为“生病之后才明白了健康的重要性”，符合逻辑。「かけて」表示“在……期间/方面”；「たびに」表示“每次……都……”；「からには」表示“既然……就……”，均不符合句意。

从接续语法的角度：

「かけて」接续用法是“名词+にかけて”；「たびに」接续用法是“动词连体形+たびに”或“名词+のたびに”；「からには」接续用法是“动词终止形+からには”。都不符合接续。

## 形容词的活用形

| 活用形 | 规则   | 主要用法        |
| --- | ---- | ----------- |
| 未然形 | かろ   | 后接う表示推量     |
| 連用形 | く・かっ | 构成ない形、て形、た形 |
| 終止形 | い    | 句子结尾（原形）    |
| 連体形 | い    | 连接名词（原形）    |
| 仮定形 | けれ   | 构成ば形        |

#### 形容词无命令形。

## 形容动词的活用形

| 活用形 | 规则     | 主要用法        |
| --- | ------ | ----------- |
| 未然形 | だろ     | 后接う表示推量     |
| 連用形 | で・に・だっ | 中顿、副词化、构成た形 |
| 終止形 | だ      | 句子结尾（原形）    |
| 連体形 | な      | 连接名词（原形）    |
| 仮定形 | なら     | 构成ば形        |
