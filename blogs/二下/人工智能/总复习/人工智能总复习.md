# 机器学习

机器学习根据数据标签情况和学习方式，主要分为**监督学习**、**半监督学习**、**无监督学习**、**强化学习**四大类。其中，监督学习是应用最广、理论最成熟的分支。

## 监督学习核心要素

### 概念

监督学习是机器学习中最成熟、应用最广泛的分支，其核心在于利用**带标签的数据**训练模型，使其能够对新样本进行预测。四个核心要素相互关联，共同决定了模型的学习效果。

### 核心要素

- **标注数据**：输入 $x$ 与对应的真实标签 $y$ 构成的训练样本 $(x, y)$，是模型学习的"教材"。
- **学习模型（映射函数）**：从输入空间到输出空间的映射 $f: \mathcal{X} \to \mathcal{Y}$，用于对新样本进行预测，是学习的"成果"。
- **损失函数**：衡量模型预测值 $\hat{y}$ 与真实值 $y$ 之间差异的函数，是优化的"目标"。
- **优化方法**：通过迭代调整模型参数以最小化损失函数的算法，如梯度下降法，是达到目标的"路径"。

### 常见损失函数

损失函数的选择取决于任务类型（回归还是分类）以及数据的分布特性。

| 损失函数                     | 公式                                                               |  适用任务   | 特点                                 |
| :----------------------- | :--------------------------------------------------------------- | :-----: | :--------------------------------- |
| **均方误差（MSE）**            | $$L = \frac{1}{n}\sum_{i=1}^{n} (y_i - \hat{y}_i)^2$$            |   回归    | 对大误差惩罚较重（平方放大），对异常值敏感；可导且凸，易于优化    |
| **平均绝对误差（MAE）**          | $$L = \frac{1}{n}\sum_{i=1}^{n}\|y_i - \hat{y}_i\| $$            |   回归    | 对异常值鲁棒，但零点处不可导                     |
| **交叉熵损失（Cross-Entropy）** | $$L = -\sum_{i} y_i \log(\hat{y}_i) + (1-y_i)\log(1-\hat{y}_i)$$ | **二分类** | 衡量两个概率分布的差异，配合 Sigmoid 输出使用，梯度更新稳定 |
| **多分类交叉熵损失**             | $$L = -\sum_{i} \sum_{k} y_{ik} \log(\hat{y}_{ik})$$             | **多分类** | 二分类交叉熵的推广，配合 Softmax 输出使用          |
| **Hinge Loss（合页损失）**     | $$L = \sum_{i} \max(0, 1 - y_i \hat{y}_i)$$                      | **二分类** | SVM 的损失函数，关注分类间隔，不仅要求分对还要分得足够"开"   |

> **选型指南**：
> - **回归任务** → 首选 **MSE**（数据干净无异常值时），若存在异常值可考虑 **MAE** 或 **Huber Loss**（MSE 和 MAE 的折中）。
> - **二分类任务** → 首选 **交叉熵损失**（逻辑回归、神经网络），**Hinge Loss** 用于 SVM。
> - **多分类任务** → 首选 **多分类交叉熵损失**（配合 Softmax）。

## 机器学习的任务类型

### 概念

机器学习模型要解决的任务可以按照**输出形式**和**数据是否有标签**划分为四种基本类型：分类、回归、聚类、降维。其中分类和回归属于监督学习，聚类和降维属于无监督学习。

| 任务类型 | 标签情况 | 输出类型 | 核心目标 | 生活类比 |
| :--- | :--- | :--- | :--- | :--- |
| **分类** | 有标签（监督） | 离散类别 | 判断样本属于哪一类 | 区分苹果和香蕉（定性） |
| **回归** | 有标签（监督） | 连续数值 | 预测具体数值 | 预测苹果的重量（定量） |
| **聚类** | 无标签（无监督） | 天然群组 | 发现数据中的族群结构 | 把水果按形状自动分堆 |
| **降维** | 通常无监督 | 精简表示 | 压缩数据、消除冗余 | 将 100 个特征浓缩为 2 个核心指标 |

### 分类

**概念**：分类任务的目标是预测样本所属的**离散类别**。模型学习的是输入特征与类别标签之间的决策边界。

- **输出**：有限个离散值，如 0/1、猫/狗/汽车
- **常见算法**：对数几率回归（逻辑回归）、Softmax、支持向量机（SVM）、决策树、随机森林、神经网络
- **经典应用**：垃圾邮件识别、图像分类、疾病诊断、信用评分

### 回归

**概念**：回归任务的目标是预测一个**连续的数值**。模型学习的是输入特征与输出数值之间的函数映射关系。

- **输出**：实数域上的连续值，如价格、温度、销售额
- **常见算法**：线性回归、多项式回归、岭回归、决策树回归、神经网络
- **经典应用**：房价预测、气温预测、股票价格预测、销量预测

> **易混淆概念**：对数几率回归（Logistic Regression）虽然名字带"回归"，但它属于**分类**任务，而非回归任务。

### 聚类

**概念**：聚类属于**无监督学习**，数据没有标签。其目标是在无先验知识的情况下，将数据划分为若干个"簇"，使得**簇内样本相似度高、簇间样本相似度低**（"物以类聚"）。

- **输出**：样本所属的簇编号（天然分组）
- **常见算法**：K-Means、层次聚类（HC）、DBSCAN（基于密度的聚类）
- **经典应用**：客户分群、新闻主题聚类、图像分割、异常检测（孤立点）

### 降维

**概念**：降维通常作为一种**数据预处理手段**，而非最终任务。其目标是将高维数据映射到低维空间，在尽可能保留重要信息的同时，消除冗余特征和噪声，缓解"维度灾难"。

- **输出**：更低维度的数据表示
- **常见算法**：主成分分析（PCA，无监督）、t-SNE（可视化）、线性判别分析（LDA，有监督）
- **经典应用**：数据可视化（将高维数据压缩到 2 D/3 D 便于观察）、特征压缩加速训练

### 四种任务的实际组合

在实际项目中，这四种任务通常是组合使用的：

1. **降维 + 分类/回归**：当特征维度很高时，先用 PCA 压缩，再训练模型，可显著提速并提升泛化能力。
2. **聚类 + 分类**：在数据没有标签时，可先聚类生成"伪标签"，再训练分类模型（半监督学习）。
3. **降维 + 聚类**：高维数据下距离度量容易失效（维度灾难），先降维再聚类效果更稳定。

## 过拟合与欠拟合

过拟合和欠拟合是**监督学习**中的两个核心概念，描述了模型复杂度与泛化能力之间的关系。

| 训练损失 | 测试损失 | 结论         |
| ---- | ---- | ---------- |
| 小    | 小    | 泛化能力强，模型较为理想      |
| 小    | 大    | 过拟合（模型过于复杂，记住了训练数据中的噪声） |
| 大    | 大    | 欠拟合（模型过于简单，未能捕捉数据规律） |
| 大    | 小    | 不可能出现      |

## 分类模型评估指标

### 概念

分类模型的评估不能仅看准确率，尤其在**类别不平衡**的场景下（如欺诈检测中正样本仅占 1%），准确率会失效。需要引入**混淆矩阵**及衍生指标进行全面评估。

### 混淆矩阵

混淆矩阵是一个 $2 \times 2$ 的表格，用于描述分类结果与真实标签之间的关系：

| 真实 \ 预测 | 预测为正例（Positive） | 预测为负例（Negative） |
| :---: | :---: | :---: |
| **实际为正例** | **TP（真正例）**：预测正确，正类被检出 | **FN（假负例）**：预测错误，正类被漏掉（**漏报**） |
| **实际为负例** | **FP（假正例）**：预测错误，负类被误报（**误报**） | **TN（真负例）**：预测正确，负类被排除 |

> **记忆口诀**：T/F 表示预测**对/错**，P/N 表示预测的**结果类别**。例如 FN = 预测为 N（负例）且预测错了 → 实际是正例但被漏掉了。

### 准确率（Accuracy）

**概念**：所有样本中，预测正确的比例。是最直观的评估指标。

**公式**：
$$\text{Accuracy} = \frac{TP + TN}{TP + TN + FP + FN}$$

**局限性**：在类别不平衡时失效。例如：99 个负例 + 1 个正例，模型把所有样本都预测为负例，准确率为 99%，但这个模型毫无意义。

### 精确率（Precision）

**概念**：预测为正例的样本中，**实际真正为正例的比例**。衡量模型的"**查准率**"——预测为正的有多准。

**公式**：
$$\text{Precision} = \frac{TP}{TP + FP}$$

**适用场景**：**误报代价高**的任务。如垃圾邮件过滤——宁可漏掉几封垃圾邮件，也不要把正常邮件误判为垃圾邮件。

### 召回率（Recall）

**概念**：所有真实正例中，**被正确预测出来的比例**。衡量模型的"**查全率**"——正例被找出了多少。

**公式**：
$$\text{Recall} = \frac{TP}{TP + FN}$$

**适用场景**：**漏报代价高**的任务。如疾病筛查——宁可误判健康人为患病（进一步复查），也不能漏掉真正的病人。

### F 1-Score

**概念**：精确率和召回率的**调和平均数**，综合衡量二者，避免偏向某一方。当 Precision 和 Recall 都高时，F 1 才高。

**公式**：
$$F_1 = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}$$

### 总结对比

| 指标 | 公式 | 关注点 | 适用场景 |
| :--- | :--- | :--- | :--- |
| **准确率** | $\frac{TP+TN}{TP+TN+FP+FN}$ | 整体正确率 | 类别均衡时 |
| **精确率** | $\frac{TP}{TP+FP}$ | 误报代价（FP） | 垃圾邮件过滤 |
| **召回率** | $\frac{TP}{TP+FN}$ | 漏报代价（FN） | 疾病筛查、故障检测 |
| **F 1-Score** | 精确率与召回率的调和平均 | 综合平衡 | 两者都重要时 |

## 正则化

### 目的

正则化的核心目的是通过对模型参数（这里是权重 $w$）施加约束，限制模型复杂度，从而**防止过拟合**，提升泛化能力。

### L 1 正则化

$$L(w) = Loss + \lambda \|w\|_1$$

L 1 正则化会产生**稀疏解**，即能够将部分不重要的权重压缩为 0，因此具有**特征选择**的作用。

### L 2 正则化

$$L(w) = Loss + \lambda \|w\|_2^2$$

L 2 正则化会让所有权重都变小但不会变为 0，因此也称为**权重衰减**，可以有效抑制过大权重带来的过拟合风险。

### 注意

- 正则化项必须与模型参数 $w$ 有关。如果写成 $\lambda Y^T Y$（只和数据有关，和 $w$ 无关），则起不到正则化作用。
- $\lambda$ 必须大于 0。如果 $\lambda < 0$，则相当于鼓励 $w$ 增大，与正则化目标相反，会加剧过拟合。

## 线性回归-回归

### 模型概念

线性回归是一种**监督学习**模型，用于**回归任务**，其输出是连续值。模型假设输入与输出之间存在线性关系。

### 模型表达式

$$f(x_i) = w x_i + b$$

其中 $w$ 为权重，$b$ 为偏置，输出为连续值。

### 损失函数-平方损失

采用**平方损失（均方误差，MSE）**，衡量预测值与真实值之间的差距：

$$L(w,b) = \sum_{i=1}^{n} (y_i - (wx_i + b))^2$$

### 优化方法

- **最小二乘法**：对 $w$ 和 $b$ 求偏导并令其等于 0，直接解出解析解（**闭式解**）。
- **梯度下降法**：$w = w - \eta \frac{\partial L}{\partial w}$，通过迭代逐步逼近最优解。

### 闭式解公式

$$w = \frac{\sum_{i=1}^{n} (x_i - \bar{x})(y_i - \bar{y})}{\sum_{i=1}^{n} (x_i - \bar{x})^2}$$

$$b = \bar{y} - w\bar{x}$$

> **注意**：$x_i$ 是单个样本值，$\bar{x}$ 是所有 $x$ 的平均值。

## 对数几率回归-分类

### 模型概念

对数几率回归（Logistic Regression）虽然名字中包含"回归"，但实际上是一种**分类模型**，用于**二分类**任务。它通过对数几率函数将线性回归的输出映射到概率空间，输出值表示样本属于正类的概率。

### 模型表达式

将线性回归的结果通过 Sigmoid 函数映射到 $(0,1)$ 之间，表示属于类别 1 的概率：

$$\hat{y} = \frac{1}{1 + e^{-(w^T x + b)}}$$

其中 $w^T x + b$ 为线性回归的输出，Sigmoid 函数将其压缩到概率区间。

### 损失函数-交叉熵损失

采用**交叉熵损失（二元交叉熵）**，衡量预测概率分布与真实标签之间的差异：

$$L(\theta) = -\sum_{i=1}^{n} [y_i \log(f_\theta(x_i)) + (1-y_i)\log(1-f_\theta(x_i))]$$

### 梯度与参数更新

损失函数对参数 $\theta_j$ 的梯度为：

$$\frac{\partial L}{\partial \theta_j} = \sum_{i=1}^{n} (f_\theta(x_i) - y_i) x_{ij}$$

采用梯度下降法更新参数：

$$\theta_j = \theta_j - \eta \sum_{i=1}^{n} (f_\theta(x_i) - y_i) x_{ij}$$

## Softmax-多分类

### 模型概念

Softmax 是逻辑回归在多分类任务中的推广，可以将多个类别的输出转换为概率分布。它通常作为神经网络的输出层激活函数，用于处理类别数大于 2 的分类问题。

### 模型表达式

$$y_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$$

其中 $z_i$ 为第 $i$ 个类别的线性输出，$y_i$ 为归一化后的概率值。

### 核心作用

将多个输出值转换为概率分布，使得所有类别概率之和等于 1。这样可以直观地解释为样本属于各个类别的置信度。

### 损失函数-多分类交叉熵损失

采用**多分类交叉熵损失**：

$$L = -\sum_{i=1}^{n} \sum_{k=1}^{K} y_{ik} \log(\hat{y}_{ik})$$

其中 $K$ 为类别总数，$y_{ik}$ 为真实标签的 one-hot 编码，$\hat{y}_{ik}$ 为 Softmax 输出的预测概率。

## 线性判别分析 LDA/FDA

### 模型概念

线性判别分析（Linear Discriminant Analysis, LDA），也称 Fisher 判别分析（FDA），是一种**有监督的降维方法**。其核心思想是寻找一个最优投影方向，使得投影后同类样本尽量集中（类内方差小），不同类样本尽量分开（类间均值差大）。

### Fisher 准则

$$J(w) = \frac{\|m_2 - m_1\|_2^2}{s_1^2 + s_2^2}$$

其中 $m_1, m_2$ 为两类样本投影后的均值，$s_1^2, s_2^2$ 为两类样本投影后的方差。该准则的目标是最大化类间均值差与类内方差之比。

### 核心特点

- **有监督**：利用类别标签信息指导降维方向
- **降维+分类**：既可用于数据降维，也可直接用于分类
- **最大化可分性**：使得降维后的数据更易于区分

## 支持向量机 SVM -分类

### 模型概念

支持向量机（Support Vector Machine, SVM）是一种经典的**二分类**模型，其核心思想是找到一个**最大化分类间隔**的超平面，从而获得更好的泛化能力。SVM 基于结构风险最小化原则，在有限样本下具有较强的推广能力。

### 核心思想

找一个超平面 $w^T x + b = 0$，使得两类样本离该平面的距离（间隔）最大。间隔越大，模型的泛化误差上界越小。

### 硬间隔 SVM

要求所有样本都被正确分类且满足间隔约束：

$$\min_{w,b} \frac{1}{2}\|w\|^2$$

约束条件：

$$y_i(w^T x_i + b) \geq 1, \quad \forall i = 1, \dots, n$$

### 软间隔 SVM

引入松弛变量 $\xi_i$，允许少量样本被分错，增强模型对噪声和异常点的鲁棒性：

$$\min_{w,b} \frac{1}{2} w^T w + C \sum_{i=1}^n \max(0, 1 - y_i(w^T x_i + b))$$

其中 $C > 0$ 为正则化参数，控制间隔大小与误分类惩罚之间的平衡：$C$ 越大，对误分类的惩罚越重，模型倾向于更小的间隔；$C$ 越小，允许更多样本违反间隔约束，模型倾向于更大的间隔。

### 重要概念

**支持向量**是离分类超平面最近的那些样本点，即满足 $y_i(w^T x_i + b) = 1$ 的样本。只有支持向量决定了分类边界，其他远离边界的样本点不影响超平面的位置和方向。这一特性使得 SVM 具有较好的稀疏性和鲁棒性。

## 决策树-分类与回归

### 模型概念

决策树是一种基于树结构的分类与回归模型，通过递归地选择最优特征对数据进行划分，具有**可解释性强**、**可视化好**、**无需数据预处理**等优点。其基本流程包括特征选择、决策树生成和决策树剪枝三个步骤。

### 划分度量

决策树的关键在于如何选择最优划分特征，不同的划分度量对应不同的经典算法：

| 指标 | 对应算法 | 选择准则 | 核心思想 |
|------|----------|----------|----------|
| 信息增益 | ID 3 | 越大越好 | 衡量特征使系统不确定性减少的程度 |
| 信息增益率 | C 4.5 | 越大越好 | 对信息增益进行归一化，偏向取值较少的特征 |
| 基尼系数 | CART | 越小越好 | 衡量从数据集中随机抽取两个样本类别不一致的概率 |

### 计算公式

**信息熵**（衡量数据集的不确定性）：

$$H(Y) = -\sum_{k} P(Y=y_k) \log_2 P(Y=y_k)$$

熵值越大，数据集的混乱程度越高；熵值为 0 表示数据集完全纯净。

**条件熵**（给定特征 $a$ 后，$Y$ 剩余的不确定性）：

$$H(Y|a) = -\sum_{v} P(a=a^v) \sum_{k} P(Y=y_k|a=a^v) \log_2 P(Y=y_k|a=a^v)$$

**信息增益**（特征 $a$ 带来的不确定性减少量）：

$$IG(D,a) = H(Y) - H(Y|a)$$

信息增益越大，说明该特征对分类的贡献越大。

**IV 值**（特征 $a$ 的固有值，衡量其取值分布的分散程度）：

$$IV(a) = -\sum_{v} P(a=a^v) \log_2 P(a=a^v)$$

**信息增益率**（对信息增益进行归一化处理）：

$$GainRatio = IG / IV(a)$$

信息增益率解决了 ID 3 算法偏向于选择取值较多特征的缺陷。

### 剪枝

决策树容易过拟合，通常需要通过**剪枝**来提升泛化能力：

- **预剪枝**：在决策树生成过程中，提前停止某些分支的划分。
- **后剪枝**：先完整生成决策树，再自底向上对非叶节点进行考察，若将该节点对应的子树替换为叶节点能带来泛化性能提升，则执行剪枝。

### 解题步骤

**第一步：计算根节点的总熵**
- 统计数据集中正例（Y=T）和负例（Y=F）的个数
- 代入熵公式：$H(Y) = -\sum_{k} P(Y=y_k) \log_2 P(Y=y_k)$

**第二步：计算每个候选属性的条件熵**
- 对每个属性，按取值划分子集
- 计算每个子集的熵：$H(Y|a=v) = -\sum_k P(Y=y_k|a=v) \log_2 P(Y=y_k|a=v)$
- 加权求和得到条件熵：$H(Y|a) = \sum_v P(a=a^v) \cdot H(Y|a=a^v)$

**第三步：计算每个属性的信息增益**
- $IG(D,a) = H(Y) - H(Y|a)$
- 信息增益越大，表示该属性划分后数据纯度提升越多

**第四步：选择根节点**
- 选择信息增益**最大**的属性作为根节点
- 若多个属性增益相同，任选其一均可

**第五步：递归构建子树**
- 对当前节点的每个分支，取出对应子集
- 若子集中所有样本类别一致 → 设为叶节点
- 若子集为空 → 设为父节点中出现次数最多的类别
- 否则，重复第一步到第四步，继续划分

**第六步：绘制决策树**
- 从根节点开始，按分支画出整棵树，叶节点标注类别

## 线性分类模型总结

| 模型               |   任务类型    | 常用损失函数 / 准则                                                                     | 优化核心             |
| :--------------- | :-------: | :------------------------------------------------------------------------------ | :--------------- |
| **线性回归**         | 回归（也能二分类） | **平方损失（MSE）** ：$\sum (y_i - w^T x_i)^2$                                         | 最小二乘法（闭式解）或梯度下降  |

| **支持向量机（SVM）**   |    二分类    | **Hinge 损失 + 正则项**：$\sum \max(0, 1 - y_i w^T x_i) + \lambda \|w\|^2$            | 二次规划（QP）/ SMO    |

## 集成学习

### 模型概念

集成学习（Ensemble Learning）的核心思想是**三个臭皮匠，顶个诸葛亮**——通过组合多个弱分类器（基学习器）的预测结果，形成一个强分类器，从而显著提升整体性能。其理论基础是：多个独立模型的组合可以降低方差或偏差。

### 核心思想

把多个弱分类器组合成一个强分类器。集成学习的成功依赖于基学习器的**准确性**（每个基学习器至少比随机猜测好）和**多样性**（基学习器之间存在差异）。

### 主要集成策略

| 策略 | 代表算法 | 核心思想 |
|------|----------|----------|
| Bagging（并行式） | 随机森林 | 对训练数据进行有放回采样，训练多个基学习器，通过投票或平均进行集成，主要降低方差 |
| Boosting（串行式） | AdaBoost、GBDT、XGBoost | 串行训练基学习器，每个新学习器关注前序学习器预测错误的样本，主要降低偏差 |
| Stacking（堆叠式） | 多层级联模型 | 将多个基学习器的输出作为输入，训练一个元学习器进行最终预测 |

### 常见算法简介

- **随机森林（Random Forest）**：Bagging 的代表，基学习器为决策树，同时在样本和特征两个维度引入随机性，具有良好的抗过拟合能力。
- **AdaBoost**：Boosting 的早期代表，通过调整样本权重，使后续学习器更关注前序被错分的样本。
- **GBDT / XGBoost / LightGBM**：Boosting 的进阶版本，通过梯度提升（Gradient Boosting）框架串行训练决策树，是结构化数据竞赛中常用算法。

# 深度学习

## 深度学习 vs 机器学习

深度学习是机器学习的一个子集，核心区别在于**特征提取方式**和**模型深度**。

| 对比维度 | 机器学习     | 深度学习      |
| :--: | :------- | :-------- |
| 特征提取 | 手工设计特征工程 | 端到端自动学习特征 |
| 网络深度 | 浅层结构     | 多层非线性变换   |
| 数据需求 | 小样本也能工作  | 需要大量数据支撑  |
| 可解释性 | 较好（如决策树） | 较差（黑箱特性）  |

## 前馈神经网络（Feedforward Neural Network）

### 网络结构

由**输入层**、至少一个**隐藏层**和**输出层**构成。层与层之间**全连接**，即每个神经元都与下一层的所有神经元相连。数据从输入到输出**单向流动**，不存在反馈连接，因此称为"前馈"。

### 激活函数

激活函数为神经网络引入**非线性**，使其能够拟合任意复杂函数。若没有激活函数，多层全连接网络等价于线性变换，无法解决非线性问题。

| 函数      | 公式                                 | 特点                                                     |
| :------ | :--------------------------------- | :----------------------------------------------------- |
| Sigmoid | $$\sigma(x) = \frac{1}{1+e^{-x}}$$ | 输出范围 (0,1)，适合二分类输出层；但两端梯度接近 0，存在**梯度饱和**问题，易导致梯度消失     |
| ReLU    | $$\max(0,x)$$                      | 计算简单、速度快、正区间梯度恒为 1，有效**缓解梯度消失**；但负区间输出恒为 0，存在"神经元死亡"问题 |

### 参数初始化

**所有参数不能初始化为 0，也不能全部初始化为相同值**。

原因：若同一层神经元的参数完全相同，则前向传播时输出相同，反向传播时收到的误差梯度也完全相同，更新后参数仍然相同，导致**所有神经元学到的东西一模一样**，网络丧失表达能力。

**常用初始化方法**：Xavier 初始化（针对 Sigmoid/Tanh）、He 初始化（针对 ReLU），均通过随机小值打破对称性。

### 全连接层参数量计算

**第一步：将输入展平为一维向量**

全连接层的输入必须是**一维向量**。若输入为多维张量（如图像 $C \times H \times W$），需要先展平：

$$\text{输入维度} = C \times H \times W$$

**第二步：确定输出维度**

输出维度由任务决定，如分类任务中的类别数。

**第三步：计算参数量**

全连接层的权重矩阵形状为 $\text{输入维度} \times \text{输出维度}$：

$$\text{参数量} = \text{输入维度} \times \text{输出维度}$$

若包含偏置项（**题目没说则默认包含**），则加上输出维度：

$$\text{参数量（含偏置）} = \text{输入维度} \times \text{输出维度} + \text{输出维度}$$

## 卷积神经网络（CNN）

### 核心概念

CNN 是前馈神经网络的一种。

CNN 是专门用于处理**网格结构数据**（如图像）的神经网络，通过局部连接和权重共享大幅减少参数数量。

### 三层结构

| 层类型 | 作用 |
| :--- | :--- |
| **卷积层（Convolutional Layer）** | 卷积核在图像上滑动，做**点积运算**，提取局部特征（边缘、纹理等），具有**权重共享**和**局部连接**特性 |
| **池化层（Pooling Layer）** | 缩小特征图尺寸，常用**最大池化**（保留最显著特征）或**平均池化**（保留整体信息），具有**降维**和**平移不变性**作用 |
| **全连接层（Fully Connected Layer）** | 将提取的高层特征展平后进行分类或回归 |

### 典型处理流程

输入图像 → 【卷积 + 池化】× N（逐层提取抽象特征）→ 展平（Flatten）→ 全连接层 → Softmax 输出概率分布

### 卷积层、池化层输出尺寸计算

**公式**：
$$O = \frac{W - K + 2P}{S} + 1$$

| 符号  | 含义          |
| :-: | :---------- |
| $W$ | 输入尺寸（高度或宽度） |
| $K$ | 卷积核/池化窗口尺寸  |
| $P$ | 填充（padding） |
| $S$ | 步长（stride）  |
| $O$ | 输出尺寸        |

**注意**：
- 若计算结果不为整数，需**向下取整**：$O = \left\lfloor \frac{W - K + 2P}{S} \right\rfloor + 1$
- 输出通道数 = 卷积核个数，与公式无关
- 如果尺寸的高宽不同，则**每个方向独立计算**。
- 池化窗口步长默认等于池化窗口尺寸。
- 如果剩余宽度小于步长，则舍弃，不再移动。这就是为什么需要向下取整。

## 自注意力机制（Self-Attention）

### 核心概念

自注意力机制用于在序列中**建立每个位置与其他所有位置之间的依赖关系**，能够**捕获全局上下文信息**，是 Transformer 架构的核心组件。与 RNN 的逐步传递不同，自注意力通过一次计算直接建模任意距离的位置关系。

### QKV 计算

给定输入向量 $x_i$，通过三个可学习的权重矩阵分别计算：

$$q_i = W^Q x_i \quad \text{（查询，Query）}$$
$$k_i = W^K x_i \quad \text{（键，Key）}$$
$$v_i = W^V x_i \quad \text{（值，Value）}$$

其中 $q_i$ 表示"我想查询什么"，$k_j$ 表示"我有什么可被匹配的特征"，$v_j$ 表示"我实际包含的信息内容"。

### 计算步骤

**步骤一**：计算注意力分数（点积），并缩放：

$$\alpha_{ij} = \frac{q_i \cdot k_j}{\sqrt{d_k}}$$

除以 $\sqrt{d_k}$（$d_k$ 为向量维度）的目的是**防止点积结果过大**，避免 Softmax 输出落入梯度饱和区，导致梯度消失。

**步骤二**：对每一行做 Softmax 归一化，得到注意力权重：

$$\hat{\alpha}_{ij} = \frac{\exp(\alpha_{ij})}{\sum_j \exp(\alpha_{ij})}$$

**步骤三**：用注意力权重对 $v_j$ 加权求和，得到最终输出：

$$o_i = \sum_j \hat{\alpha}_{ij} \cdot v_j$$

### 位置编码

自注意力本身是**置换不变的**——打乱输入顺序不影响输出结果，因此**不具备位置信息**。需要额外加入**位置编码向量** $e^i$ 来注入位置信息，常用方式为正弦位置编码或可学习位置嵌入。

## Transformer

### 核心概念

Transformer 是一种完全基于**自注意力机制**的序列到序列（Seq 2 Seq）模型，解决了 RNN 无法并行计算、难以捕获长距离依赖的缺陷，是现代大语言模型的基石。

### 整体架构

由 **编码器（Encoder）** 和 **解码器（Decoder）** 堆叠而成：

| 组件 | 子层构成 | 作用 |
| :--- | :--- | :--- |
| **Encoder** | 多头自注意力 + 前馈网络（FFN） | 对输入序列进行编码，提取深层语义特征 |
| **Decoder** | 掩码自注意力 + Encoder-Decoder 注意力 + 前馈网络 | 根据编码器输出和已生成内容，逐步生成目标序列 |

其中**掩码自注意力**通过遮盖未来位置信息，确保解码时只能看到已生成的部分，防止"作弊"。

## BERT vs GPT

### 核心概念

BERT 和 GPT 是基于 Transformer 的两大预训练语言模型代表，它们在训练目标和应用场景上有本质区别。

| 对比维度 | BERT | GPT |
| :---: | :--- | :--- |
| **训练方式** | 掩码语言模型（MLM）：随机遮盖 15% 的 Token，训练模型"**挖空填词**" | 自回归语言模型：给定左侧上下文，训练模型"**预测下一个 Token**" |
| **注意力方向** | **双向**（同时看到左右两侧上下文） | **单向**（只能看到左侧上下文） |
| **适用场景** | **理解类**任务：文本分类、命名实体识别、问答匹配 | **生成类**任务：文本生成、对话系统、代码生成 |

### In-Context Learning（上下文学习）

**不给模型更新参数**，仅在输入中提供**几个示例（Few-shot）** 或**任务描述（Zero-shot）**，让模型根据上下文理解任务并完成推理。这是大语言模型的重要能力，体现了模型的**元学习**特性。

### 微调（Fine-tuning）

在预训练模型的基础上，使用**下游任务的有标注数据**继续训练，使模型适应特定任务。微调时通常**更新全部或部分参数**，是迁移学习的典型应用。

## Agent 智能体

### 核心概念

Agent（智能体）是基于大语言模型的**自主决策系统**，能够感知环境、制定计划并执行动作以完成复杂任务。与普通 LLM 的被动问答不同，Agent 具备**主动性和工具使用能力**。

### 架构四要素

| 要素                     | 含义                                                           |
| :--------------------- | :----------------------------------------------------------- |
| **上下文（Context）**       | 系统指令、角色设定、环境状态、历史对话等背景信息，约束和引导 Agent 的行为                     |
| **提示词（Prompt）**        | 用户输入的具体任务指令，触发 Agent 进行推理和决策                                 |
| **工具调用（Tool Calling）** | Agent 主动调用外部工具（搜索引擎、API、代码执行器、数据库等）获取实时信息或执行操作，突破 LLM 的知识边界  |
| **记忆（Memory）**         | 分为**短期记忆**（当前对话上下文）和**长期记忆**（向量数据库存储的历史经验），支撑 Agent 的持续学习和推理 |

## 主成分分析 PCA

### 核心思想

PCA 是一种**无监督的线性降维方法**，其核心思想是**将高维数据投影到方差最大的方向上**，同时使得**重构误差最小**。这两个视角在数学上是等价的。

- **最大方差视角**：找到 $K$ 个正交方向，使得数据在这些方向上的投影方差最大，尽可能保留数据的分布信息。
- **最小重构误差视角**：找到 $K$ 个正交方向，使得数据投影到这些方向后再还原回去，误差最小。

[task]  
[question]  
**（1）为什么要往最大方差方向投影？**  

**（2）从最小化重构误差的角度理解 PCA 的优化目标：**  
$$\min_{\{w^1,\dots,w^K\}} \sum_{i=1}^{N} \left\| (x_i - \bar{x}) - \sum_{k=1}^{K} c_{i,k} w^k \right\|_2^2$$  
其中各 $w^k$ 互相正交且 $\|w^k\| = 1$。请解释该公式的物理含义，并说明为什么最大化方差与最小化重构误差是等价的。  
[\question]  
[answer]  
**（1）** 方差越大，数据分布越分散，包含的信息量越多；保留最大方差方向就是在降维时尽可能不丢信息。  

**（2）** 公式含义：将每个去中心化样本投影到 $K$ 个正交基张成的子空间再还原，让还原前后的误差总和最小。等价性：误差平方 = 总方差 − 投影方差，所以误差最小 ⇔ 投影方差最大。  
[\answer]  
[analysis]  
**（1）**
- 方差表示数据的离散程度，是信息量的度量。方差小的方向，数据点几乎挤在一起，差异极小，可以视为噪声或冗余信息。  
- 降维的目的是**压缩数据但保留核心信息**，因此把数据往方差最大的方向上投影，才能在低维空间中尽可能还原原始数据的分布结构。  

**（2）**

整个公式衡量的是 **重构误差**：原始数据与投影后再重构的数据之间的欧氏距离平方和。  

**为什么等价？** 固定总方差时，误差平方 = 总方差 − 投影方差（勾股定理），两者互为补数。最小化误差平方必然最大化投影方差——本质是同一优化目标在两个视角下的数学等价表达。

### 优化目标

$$\min_{\{w^1,\dots,w^K\}} \sum_{i=1}^{N} \left\| (x_i - \bar{x}) - \sum_{k=1}^{K} c_{i,k} w^k \right\|_2^2$$

其中各 $w^k$ 互相正交且 $\|w^k\| = 1$，$c_{i,k}$ 是投影系数。

### 求解方法

对数据协方差矩阵 $X^T X$ 做**特征值分解**，取前 $K$ 个最大特征值对应的特征向量作为主成分方向。最优的 $K$ 个投影方向就是这些特征向量。

### 本质与局限

- **本质**：PCA 是在线性变换下保留方差最大的投影方向，是一种线性降维方法。
- **局限**：仅能捕捉数据的线性结构，无法处理非线性流形数据（如瑞士卷、螺旋线）。

## 自编码器 vs 变分自编码器

### 自编码器（Autoencoder）

**结构**：编码器（Encoder）+ 解码器（Decoder）。编码器将输入压缩成低维编码，解码器将编码还原为原始输入。

**目标**：最小化重构误差，即让输出尽可能接近输入。

**隐空间特点**：编码是确定性的**一个点**，隐空间不连续，不同样本的编码之间可能存在“空洞”。

**局限性**：只能还原训练集中的样本，**无法生成新样本**——因为从隐空间中任意采一个点，解码器输出的可能毫无意义。

### 变分自编码器（VAE）

**核心改进**：编码器输出的不是**一个点**，而是**一个分布**（均值和方差），从这个分布中采样得到编码，再送入解码器。

**目标函数**：**重构损失 + KL 散度**
- **重构损失**：保证生成的图像与输入相似。
- **KL 散度**：强迫隐空间的分布接近标准正态分布 $\mathcal{N}(0, I)$。

**为什么需要 KL 散度？**
- 如果没有 KL 散度，编码器会让方差无限趋近于 0，退化成普通自编码器。
- KL 散度保证隐空间**连续且有规律**，任意从 $\mathcal{N}(0, I)$ 采一个点，解码器都能生成合理图像，且可以在隐空间进行插值。

**对比总结**：

| | 自编码器 | VAE |
| :---: | :--- | :--- |
| **隐空间** | 确定性的一个点 | 概率分布（均值 + 方差） |
| **目标函数** | 只有重构损失 | 重构损失 + KL 散度 |
| **隐空间连续性** | 不连续，存在空洞 | 连续且平滑 |
| **能否生成新样本** | 不能 | 能（从标准正态分布采样） |
| **能否在隐空间插值** | 不能（插值可能产生无意义输出） | 能（如两张人脸之间的平滑过渡） |

## 扩散模型

### 核心思想

扩散模型通过**逐步加噪**和**逐步去噪**两个过程实现图像生成。

**前向过程（加噪）**：从真实图像 $x_0$ 开始，逐步添加微小的高斯噪声，经过 $T$ 步后变成纯高斯噪声 $x_T \sim \mathcal{N}(0, I)$。这是一个固定的、不可逆的马尔可夫链。

**反向过程（去噪）**：训练一个神经网络（通常为 U-Net），学习从纯噪声 $x_T$ 中一步步恢复出原始图像 $x_0$。每一步预测噪声，然后减去该噪声。

**训练目标**：预测每一步添加的噪声 $\epsilon$，使预测噪声与真实添加的噪声之间的均方误差最小。

### 与 VAE 的对比

| | VAE | 扩散模型 |
| :---: | :--- | :--- |
| **映射方式** | 一步映射（输入 → 隐变量 → 输出） | 多步逐步加噪/去噪（$T$ 步马尔可夫链） |
| **生成质量** | 一般（图像偏模糊） | 高（当前 SOTA，如 DALL-E 2、Stable Diffusion） |
| **训练稳定性** | 较稳定（变分下界优化） | 较稳定（简单的 MSE 预测噪声） |
| **采样速度** | 快（单次前向传播） | 慢（需要迭代 $T$ 步，通常 $T=1000$） |

## 生成对抗网络 GAN

### 核心思想

GAN 由一个**生成器（Generator）** 和一个**判别器（Discriminator）** 组成，两者进行**对抗训练**。

- **生成器**：从随机噪声 $z \sim \mathcal{N}(0, I)$ 生成“假图像”，试图骗过判别器。
- **判别器**：接收真实图像和生成图像，判断输入是“真”还是“假”。

**训练过程**：
- 判别器的目标：提高区分真假的能力（最大化准确率）。
- 生成器的目标：生成更逼真的图像，使判别器无法区分（最小化被识破的概率）。

**零和博弈**：这是一个竞争关系——生成器越强，判别器也越强，最终达到**纳什均衡**，生成器可以生成以假乱真的图像。

### 目标函数

$$\min_G \max_D V(D,G) = \mathbb{E}_{x \sim p_{\text{data}}(x)}[\log D(x)] + \mathbb{E}_{z \sim p_z(z)}[\log(1 - D(G(z)))]$$

- $D(x)$ 表示判别器认为真实图像为真的概率。
- $D(G(z))$ 表示判别器认为生成图像为真的概率。

### 与扩散模型的对比

| | GAN | 扩散模型 |
| :---: | :--- | :--- |
| **训练方式** | 对抗训练（生成器与判别器博弈） | 简单的 MSE 预测噪声 |
| **训练稳定性** | 差（容易模式崩塌、梯度不稳定） | 稳定（优化目标明确） |
| **生成质量** | 高（逼真度高） | 高（当前 SOTA） |
| **多样性** | 差（容易模式崩塌，生成样本单一） | 好（多样性丰富） |
| **采样速度** | 快（单次前向传播） | 慢（迭代多步去噪） |

# 强化学习

## 核心概念

强化学习（Reinforcement Learning, RL）是一种通过**与环境交互试错**来学习最优决策的机器学习范式。智能体（Agent）在环境中不断尝试动作，根据环境反馈的奖励信号调整策略，目标是最大化累积奖励。

| 概念 | 符号 | 定义 |
| :---: | :---: | :--- |
| **状态（State）** | $s$ | 智能体当前观察到的环境信息 |
| **动作（Action）** | $a$ | 智能体在当前状态下可以执行的操作 |
| **奖励（Reward）** | $r$ | 环境对智能体动作的即时反馈，可正可负（正=鼓励，负=惩罚） |
| **策略（Policy）** | $\pi(s) \to a$ | 从状态到动作的映射规则，决定智能体在每种状态下该做什么 |
| **回报（Return）** | $G_t$ | 从时刻 $t$ 开始到回合结束，所有折扣奖励的累计和 |
| **折扣因子** | $\gamma \in [0,1]$ | 控制未来奖励的权重，越接近 1 越重视长期收益，越接近 0 越短视 |

**回报的数学定义**：

$$G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k r_{t+k+1}$$

**折扣因子的作用**：
- $\gamma$ 接近 0：智能体只看眼前奖励（短视）。
- $\gamma$ 接近 1：智能体重视未来奖励（远视），会为了长期收益牺牲短期利益。
- 数学上，折扣因子保证无限时长的回报收敛（$0 < \gamma < 1$ 时级数收敛）。


## 价值函数

价值函数用于评估**某个状态或某个动作到底有多好**。

| 价值函数 | 符号 | 含义 |
| :--- | :---: | :--- |
| **状态价值函数** | $V_\pi(s)$ | 在状态 $s$ 下，按照策略 $\pi$ 选择动作，能获得的期望回报 |
| **动作价值函数** | $Q_\pi(s,a)$ | 在状态 $s$ 下，**先执行动作 $a$**，之后按策略 $\pi$ 行动，能获得的期望回报 |

**两个核心关系**：

1. **状态价值 = 所有动作价值的加权平均**（按策略概率加权）：
   $$V_\pi(s) = \sum_{a} \pi(a|s) \cdot Q_\pi(s,a)$$

2. **动作价值 = 即时奖励 + 下一状态的折扣价值**（考虑转移概率）：
   $$Q_\pi(s,a) = \sum_{s'} P(s'|s,a) \cdot \left[ R(s,a,s') + \gamma V_\pi(s') \right]$$

   - $P(s'|s,a)$：执行动作 $a$ 后转移到 $s'$ 的概率（环境动力学）
   - $R(s,a,s')$：转移过程中获得的即时奖励


## 贝尔曼方程

**核心思想**：当前状态的价值 = 即时奖励 + 下一状态价值的折扣值——将价值函数分解为“当前回报 + 未来价值”的递归形式，使得原本难以直接计算的长远回报，变成了可以用动态规划求解的迭代问题。

$$V_\pi(s) = \mathbb{E}_\pi \left[ R_{t+1} + \gamma V_\pi(S_{t+1}) \,\middle|\, S_t = s \right]$$

**为什么重要？**
- 将价值函数的计算转化为**递归形式**，可用动态规划求解。
- 所有强化学习算法的理论基础。


## 策略评估方法

根据智能体是否知晓环境模型（状态转移概率 $P(s'|s,a)$ 和奖励函数 $R$），强化学习方法可分为两类：

| 方法 | 类型 | 是否需要环境模型 | 特点 |
| :--- | :---: | :---: | :--- |
| **动态规划** | Model-based | ✅ 需要 | 已知完整的 MDP 模型，通过迭代更新价值函数，再贪心提取策略 |
| **蒙特卡洛** | Model-free | ❌ 不需要 | 完整走完一个回合（Episode）后，用实际观测到的累积奖励 $G_t$ 更新价值函数，**回合结束后才能更新** |
| **时序差分（TD）** | Model-free | ❌ 不需要 | 边走边学，每走一步就用当前奖励 + 下一状态价值估计来更新，**无须等待回合结束** |


## 策略优化

### 策略优化定理

给定当前状态，选择能使 $Q$ 值最大的动作作为确定性策略：

$$\pi'(s) = \arg\max_a Q_\pi(s,a)$$

**含义**：如果已知 $Q$ 值表，那么最优策略就是——在每个状态 $s$ 下，选择 $Q$ 值最大的动作。这个定理保证了策略提升的单调性：$\pi'$ 一定不差于 $\pi$。

### On-Policy vs Off-Policy

| | On-Policy | Off-Policy |
| :---: | :--- | :--- |
| **定义** | 用于学习的策略 = 用于行动的策略 | 用于学习的策略 ≠ 用于行动的策略 |
| **数据来源** | 自己探索产生的数据 | 自己或其他智能体产生的数据均可 |
| **能否复用历史数据** | 不能（数据必须来自当前策略） | 能（可利用经验回放） |
| **代表算法** | SARSA | **Q-Learning** |


## Q-Learning

### 核心思想

Q-Learning 是强化学习中最经典的 **Off-Policy**（异策略） 算法。它直接学习一个 $Q$ 值表，表中记录每个状态-动作对的价值。它的核心思路是：

1. 用当前策略去探索环境，采集 $(s, a, r, s')$ 数据。
2. 更新时，**假装下一状态采用最优动作**（$\max_{a'} Q(s', a')$），而不是用当前策略实际采取的动作。
3. 这相当于在学习过程中“贪心”地估计下一状态的价值，让 $Q$ 值表直接逼近最优 $Q$ 值（$Q^*$）。

### Q 值更新公式

$$Q(s,a) \leftarrow Q(s,a) + \alpha \left[ R + \gamma \max_{a'} Q(s',a') - Q(s,a) \right]$$

| 符号 | 含义 |
| :---: | :--- |
| $Q(s,a)$ | 当前状态-动作的旧估计值 |
| $\alpha$ | 学习率（0~1），控制每次更新的步长 |
| $R$ | 执行动作后获得的即时奖励 |
| $\gamma$ | 折扣因子 |
| $\max_{a'} Q(s',a')$ | 新状态下**所有动作中最大的 $Q$ 值**（这就是 Off-Policy 的精髓） |
| $R + \gamma \max Q(s',a')$ | **TD Target**（时序差分目标），是 $Q(s,a)$ 应该靠近的目标值 |
| $R + \gamma \max Q(s',a') - Q(s,a)$ | **TD Error**（时序差分误差），用来调整当前估计值 |


### 算法步骤

```text
初始化 Q(s, a) 表（全部设为 0）
重复以下步骤（对于每一轮游戏）：
    初始化状态 s
    重复（对于每一步）：
        1. 在当前状态 s，以 ε-贪心策略选择动作 a
           （大部分时间选 Q 值最大的动作，小部分时间随机探索）
        2. 执行动作 a，观察奖励 R 和下一个状态 s'
        3. 在 Q 表中查找 s' 下所有动作的最大 Q 值：max Q(s', a')
        4. 更新 Q(s, a)：
           Q(s,a) ← Q(s,a) + α [ R + γ · max Q(s',a') - Q(s,a) ]
        5. 更新状态：s ← s'
    直到 s 为终止状态
```

### 为什么 Q-Learning 是 Off-Policy？

在更新 $Q(s,a)$ 时，Q-Learning 使用了 **$\max_{a'} Q(s', a')$**，也就是**假设下一步会采取最优动作**。但这个最优动作在实际探索过程中**不一定真的被采取**（实际动作可能由于 ε-贪心而选择了随机动作）。因此，Q-Learning 的更新目标与真实执行策略不一致——它是在“评价”最优策略，而不是当前正在执行的策略。这正是 Off-Policy 的定义。

### ε-贪心策略（Exploration vs Exploitation）

| 概念 | 含义 |
| :--- | :--- |
| **Exploitation（利用）** | 选择当前 Q 值最大的动作，利用已有经验获得高奖励 |
| **Exploration（探索）** | 以一定概率选择随机动作，尝试未知可能性，发现更好路径 |

$\epsilon$ -贪心策略以 (1- $\epsilon$ ) 的概率选择 $Q$ 值最大的动作（利用），以 $\epsilon$ 的概率随机选择动作（探索）。随着训练进行，$\epsilon$ 通常会逐步衰减，让模型从“大量探索”过渡到“充分利用”。

**（2）** 若智能体执行“右”动作，从状态 $s$ 转移到 $s'$，获得奖励 $R = 5$，且 $\max_{a'} Q(s', a') = 12$，$\gamma = 0.9$，$\alpha = 0.1$，请计算更新后的 $Q(s, \text{右})$ 新值。

[analysis]  
**（1）展开**  
在 $\epsilon$ -贪心策略中：
- 以 $\epsilon$ 的概率随机选择动作（探索），每个动作被选中的概率为 $\epsilon / |A|$。  
- 以 $1-\epsilon$ 的概率选择 $Q$ 值最大的动作（利用）。

**（2）展开**
