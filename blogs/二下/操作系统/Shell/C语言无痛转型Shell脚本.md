# Hello World

```bash
#!/bin/bash
echo "Hello, World!"
```

第一行的意义是告诉系统要用 bash 解释器来执行。其实就把这个看作 `#include` 就行了！（虽然它俩八竿子打不着，但你就说是不是都是第一行吧！）

`echo` 就相当于 `printf`，而且语法更简单，连格式说明符都省了！

而且，整个脚本自上而下运行，不需要什么奇怪的 main 函数，这很友好。（C 语言：所以是我的错？）

# 变量

## 变量的定义

```c
int num = 10;
char name[] = "Young";
const float PI = 3.14;
```

以上繁杂的 C 代码转化为 Shell 之后居然变得非常简洁：

```bash
num=10                # 整数
name="Young"          # 字符串（等号两边不能有空格！）
PI=3.14               # 浮点数
readonly PI           # 设置只读，类似const
```

值得注意的是：

#### ① 定义变量时无需数据类型

C 语言对着类型声明抠破头，Shell 直接摆烂：管你什么类型，nobody cares！

#### ② 等号两边不能有空格

这大概是 Shell 最大的坑，没有之一。C 语言写惯了 `num = 10` 的人，到这里直接原地爆炸。

## 变量的使用

```bash
echo $num
echo "我的名字是$name"
echo "PI的值是${PI}"
```

与 C 语言不同的是，Shell 在使用变量的时候并没有那么方便，直接写变量名是错误的，而应该：

#### 在变量名前加入美元符号 `$`，且建议用{}包裹变量名。

为啥要加 `$ ` ？因为Shell觉得：你用的时候用的是变量的值而不是变量名...

# 运算

## 算术运算

**C 语言：**
```c
int sum = 3 + 5;
int result = sum * 2;
```

**Shell 脚本：**
```bash
sum=$((3 + 5))
result=$((sum * 2))
```

Shell 的算术运算要用 `$(( ))` 包裹，大概是怕和变量搞混。毕竟变量已经够乱了，再加个运算，不得专门搞个符号区分一下？

# 条件判断

## 条件判断：if-else

```bash
if [ $age -ge 18 ]; then    
    echo "成年"
elif [ $age -ge 60 ]; then  # elif，不是else if
    echo "老年"
else
    echo "未成年"
fi                          # if倒过来写，结束标志
```

很神奇的是，括号要用中括号[]而不能用小括号 ()。

而且，不是 else if 而是 elif，C 语言那个 `else if` 在 Shell 眼里太啰嗦了，直接合并！

最好笑的是，不用大括号，而是用 `fi` 表示结束，~~我什么时候看到这样的能不笑（）~~。另外，`then` 也可以换到下一行，但这样似乎不是很好看？`then` 的作用就是大括号的上半部分——告诉你：准备好，代码块要开始了！

还有值得一提的是 Shell 里面比大小不能用>、<比较，而是类似 MIPS 一样：

| C 语言 | Shell | 含义 |
|-------|-------|------|
| == | -eq | 等于 |
| != | -ne | 不等于 |
| > | -gt | 大于 |
| < | -lt | 小于 |
| >= | -ge | 大于等于 |
| <= | -le | 小于等于 |

为啥不用>和<？因为 Shell 说：这两个符号我要用来做重定向，你们比大小就委屈一下用字母吧！（重定向是啥？别问，问就是后面的坑）

还有个很奇怪的地方，就是条件为真的时候，返回值是 0，这和 C 语言相反啊！

**C 语言**：0 是假，非 0 是真  
**Shell**：0 是真，非 0 是假

不懂，不懂，完全不懂。

## 条件判断：case

```bash
case $op in
        +) echo $((a + b)) ;;
        -) echo $((a - b)) ;;
        \*) echo $((a * b)) ;;  # *需要转义
        /) 
            if [ $b -ne 0 ]; then
                echo $((a / b))
            else
                echo "除数不能为0"
            fi
            ;;
        *) echo "不支持的运算符" ;;
esac
```

与 C 语言进行对照，基本就是：

将 C 语言中 switch 替换成 case（很神奇吧）

将 case 条件后面加上)。嗯对，只有右半边括号。

break 用 `;;` 表示。（有两个分号！比 C 语言多了一个，显得很厉害的样子）

最后用 esac 结束，好笑程度堪比 fi。（设计者大概觉得把单词倒过来写很有意思？那 while 倒过来呢？Elihw？哦这个没用上，可能是因为太丑了）

# 循环

## For 循环

**C 语言：**
```c
for (int i = 0; i < 5; i++) {
    printf("%d\n", i);
}
```

**Shell 脚本：**
```bash
# 形式1：类C风格（终于正常了）
for ((i=0; i<5; i++)); do
    echo $i
done

# 形式2：遍历列表（这是什么神仙语法）
for name in 张三 李四 王五; do
    echo "你好，$name"
done

# 形式3：遍历文件（实用到哭）
for file in *.txt; do
    echo "找到文件：$file"
done
```

Shell 的 for 循环终于有个像人的地方了——类 C 风格基本一样！而且遍历列表直接用 in，都不用定义数组！这也太爽了吧！

## While 循环

**C 语言：**
```c
int i = 0;
while (i < 5) {
    printf("%d\n", i);
    i++;
}
```

**Shell 脚本：**
```bash
i=0
while [ $i -lt 5 ]; do
    echo $i
    i=$((i + 1))
done
```

While 循环和 if 长得差不多，就是多了个 do（开始）和 done（结束）。Do 就是左大括号，done 就是右大括号，记住了！

# 数组

**C 语言：**
```c
int nums[3] = {1, 2, 3};
printf("%d\n", nums[0]);
```

**Shell 脚本：**
```bash
# 定义数组
nums=(1 2 3 4 5)
names=("张三" "李四" "王五")

# 访问单个元素
echo ${nums[0]}      # 输出1
echo ${names[1]}     # 输出李四

# 访问所有元素
echo ${nums[@]}      # 输出所有值（@表示全部）
echo ${#nums[@]}     # 获取数组长度（加#就是长度，这设计还挺直观）

# 遍历数组
for name in "${names[@]}"; do
    echo $name
done
```

Shell 的数组定义居然不用大括号，直接用括号！访问的时候反而要用大括号，这是什么反向操作？

而且@符号代表所有元素，这设计挺有意思——毕竟@长得就像把所有东西兜在一起的网。

# 参数相关

## 函数

**C 语言：**
```c
int add(int a, int b) {
    return a + b;
}
int result = add(3, 5);
```

**Shell 脚本：**
```bash
# 定义函数
add() {
    local a=$1    # $1是第一个参数，local声明局部变量
    local b=$2    # $2是第二个参数
    return $((a + b))
}

# 调用函数
add 3 5           # 注意：没有括号，参数用空格分隔
result=$?         # $?获取上一个函数的返回值
```

函数的定义居然不用写什么返回值类型、参数类型，直接写函数名+() 就行！

参数获取的方式—— `$1` 是第一个参数，`$2` 是第二个参数

而且调用函数的时候不能加括号，直接写函数名+空格+参数，这让 C 语言出身的人很不适应……

## 直接运行脚本

直接运行脚本的时候就相当于把整个脚本当作一个函数就行了，运行的时候输入 bash+脚本名+参数即可。

# 常用技巧

## 命令替换

```bash
# 把命令的执行结果赋给变量
current_date=$(date)
echo "今天是$current_date"

# 或者用反引号（老式写法）
current_date=`date`
```

用 `$()` 可以把命令的执行结果直接赋给变量，相当于 C 语言里调用 system 函数然后读取输出，但简单一万倍！

## 管道

```bash
# 把一个命令的输出传给另一个命令
ls -la | grep ".txt" | wc -l
```

管道符 `|` 绝对是 Shell 的黑科技，把一个命令的输出直接作为下一个命令的输入，C 语言要实现这个得写多少代码啊！

## 重定向

```bash
# 把输出写到文件
echo "Hello" > file.txt    # > 覆盖写入
echo "World" >> file.txt   # >> 追加写入

# 从文件读取输入
while read line; do
    echo $line
done < file.txt
```

这就是比大小不能用>和<的原因——>是输出重定向，<是输入重定向，>>是追加写入。

# 常用判断标志（必背）

除了数值比较，Shell 还有很多文件判断标志，写脚本必备：

| 标志 | 含义 |
|------|------|
| -f file | 文件是否存在且为普通文件 |
| -d dir | 目录是否存在 |
| -e file | 文件或目录是否存在 |
| -r file | 文件是否可读 |
| -w file | 文件是否可写 |
| -x file | 文件是否可执行 |
| -z str | 字符串是否为空 |
| -n str | 字符串是否非空 |

```bash
if [ -f "test.txt" ]; then
    echo "test.txt存在且是普通文件"
fi

if [ -z "$name" ]; then
    echo "name是空字符串"
fi
```

# 调试技巧

Shell 脚本出错咋办？不用慌，有调试大法：

```bash
# 在运行脚本时加-x参数
bash -x script.sh

# 或者在脚本里开启调试
#!/bin/bash -x    # 整脚本调试

# 或者只调试部分
set -x            # 从这里开始调试
# 要调试的代码
set +x            # 调试结束
```

-x 参数会显示每行命令执行的过程，相当于 C 语言的逐步调试但不用 gdb，血赚！
