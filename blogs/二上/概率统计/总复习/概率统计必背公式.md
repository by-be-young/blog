## 概率密度函数和概率分布函数

| 概念                                    | 核心公式                                                          | 与另一者的关系                                                                                                     |
| :------------------------------------ | :------------------------------------------------------------ | :---------------------------------------------------------------------------------------------------------- |
| **概率密度函数 (PDF)**<br>$f_X(x)$<br>（连续型） | $f_X(x) \ge 0$<br><br>$\int_{-\infty}^{+\infty} f_X(x)dx = 1$ | PDF 是 CDF 的**导数**：$f_X(x) = F_X'(x)$                                                                        |
| **概率分布函数 (CDF)**<br>$F_X(x)$          | $F_X(x) = P(X \le x)$<br>单调不减<br>取值范围 $[0,1]$                 | CDF 是 PDF 的**积分**：$F_X(x) = \int_{-\infty}^{x} f_X(t) dt$<br>对离散随机变量，$F_X(x) = \sum_{x_i \le x} P(X = x_i)$ |

## 常用离散型随机变量

| 分布名称  | 表示方法                | 分布律                                 | 数学期望            | 方差                                                           |
| ----- | ------------------- | ----------------------------------- | --------------- | ------------------------------------------------------------ |
| 两点分布  | $X \sim B(1, p)$    | $p^k (1-p)^{1-k}$                   | $p$             | $p(1-p)$                                                     |
| 二项分布  | $X \sim B(n, p)$    | $C_n^k p^k (1-p)^{n-k}$             | $np$            | $np(1-p)$                                                    |
| 泊松分布  | $X \sim P(\lambda)$ | $\frac{\lambda^k e^{-\lambda}}{k!}$ | $\lambda$       | $\lambda$                                                    |
| 超几何分布 | $X \sim H(N, M, n)$ | $\frac{C_M^k C_{N-M}^{n-k}}{C_N^n}$ | $n \frac{M}{N}$ | $n \frac{M}{N} \left(1 - \frac{M}{N}\right) \frac{N-n}{N-1}$ |
| 几何分布  | $X \sim G(p)$       | $(1-p)^{k-1} p$                     | $\frac{1}{p}$   | $\frac{1-p}{p^2}$                                            |

## 常用连续性随机变量

| 分布名称                                   | 概率密度函数 (PDF) $f(x)$                                                          | 概率分布函数 (CDF) $F(x)$                                                                      | 数学期望 $E(X)$         | 方差 $D(X)$             |
| :------------------------------------- | :--------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------- | :------------------ | :-------------------- |
| **均匀分布**<br>$X \sim U[a, b]$           | $\begin{cases} \frac{1}{b-a}, & a \le x \le b \\ 0, & \text{其他} \end{cases}$ | $\begin{cases} 0, & x < a \\ \frac{x-a}{b-a}, & a \le x < b \\ 1, & x \ge b \end{cases}$ | $\frac{a+b}{2}$     | $\frac{(b-a)^2}{12}$  |
| **指数分布**<br>$X \sim \epsilon(\lambda)$ | $\begin{cases} \lambda e^{-\lambda x}, & x \ge 0 \\ 0, & x < 0 \end{cases}$  | $\begin{cases} 1 - e^{-\lambda x}, & x \ge 0 \\ 0, & x < 0 \end{cases}$                  | $\frac{1}{\lambda}$ | $\frac{1}{\lambda^2}$ |

# 数字特征

近年往年题未出现过协方差矩阵。

| 概念                              | 定义/核心公式                                                                                      | 性质/说明                                                                                                 |
| :------------------------------ | :------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------- |
| **数学期望 $E(X)$**                 | **离散**：$E(X) = \sum_{i} x_i p_i$ <br><br> **连续**：$E(X) = \int_{-\infty}^{+\infty} x f(x) dx$ | **线性性**：$E(aX + bY + c) = aE(X) + bE(Y) + c$                                                          |
| **方差 $D(X)$ 或 $\text{Var}(X)$** | $D(X) = E[(X - E(X))^2] = E(X^2) - [E(X)]^2$                                                 | 衡量随机变量取值与其均值的**偏离程度**。<br>$D(aX + b) = a^2 D(X)$                                                      |
| **协方差 $\text{Cov}(X, Y)$**      | $\text{Cov}(X, Y) = E[(X - E(X))(Y - E(Y))] = E(XY) - E(X)E(Y)$                              | 衡量两个随机变量的**线性相关程度**。<br> $\text{Cov}(X, X) = D(X)$ <br> $\text{Cov}(aX+b, cY+d) = ac \text{Cov}(X,Y)$ |
| **相关系数 $\rho_{XY}$**            | $\rho_{XY} = \frac{\text{Cov}(X, Y)}{\sqrt{D(X)} \sqrt{D(Y)}}$                               | **标准化**的协方差，满足 $-1 \le \rho_{XY} \le 1$。<br> $\mid\rho_{XY}\mid=1$ 表示存在线性关系 $Y=aX+b$。                 |

| **切比雪夫不等式** | 对任意 $\varepsilon > 0$：<br> $P(\mid X - E (X)\mid \ge \varepsilon) \le \frac{D (X)}{\varepsilon^2}$ |
## 大数定律

| 定律名称         | 前提条件                                                 | 核心结论                                                                                                                                                         | 意义与说明                                                          |
| :----------- | :--------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------- |
| **切比雪夫大数定律** | 相互独立<br>方差存在且有公共上界：$D(X_i) \le C$。                   | 对任意 $\varepsilon > 0$：<br>$\lim_{n \to \infty} P\left( \mid \frac{1}{n}\sum_{i=1}^{n} X_i - \frac{1}{n}\sum_{i=1}^{n} E(X_i) \mid < \varepsilon \right) = 1$ | 在方差一致的条件下，**样本均值**依概率收敛于**期望的均值**。                             |
| **辛钦大数定律**   | 独立同分布<br>且数学期望存在。                                    | 对任意 $\varepsilon > 0$：<br> $\lim_{n \to \infty} P\left( \mid \frac{1}{n}\sum_{i=1}^{n} X_i - \mu \mid < \varepsilon \right) = 1$                             | 在**独立同分布**且期望存在的条件下，**样本均值**依概率收敛于**总体均值** $\mu$。不要求方差存在，应用更广。 |
| **伯努利大数定律**  | $n_A$ 是 $n$ 重伯努利试验中事件 $A$ 发生的次数，每次试验 $A$ 发生的概率为 $p$。 | 对任意 $\varepsilon > 0$：<br> $\lim_{n \to \infty} P\left( \mid \frac{n_A}{n} - p \mid < \varepsilon \right) = 1$                                               | **频率** $\frac{n_A}{n}$ 依概率收敛于**概率** $p$。是辛钦定律在伯努利试验（两点分布）下的特例。 |

## 中心极限定理

| 定理名称           | 前提条件                                           | 核心结论                                                                                                                                                                                                                                                                    | 意义与说明                                                                                         |
| :------------- | :--------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------- |
| **同分布中心极限定理**  | 独立同分布<br>期望存在<br>方差存在                          | $\lim_{n \to \infty} P\left( \frac{\sum_{i=1}^{n} X_i - n\mu}{\sqrt{n} \sigma} \le x \right) = \Phi(x)$ <br> 即：$\frac{\bar{X} - \mu}{\sigma / \sqrt{n}} \stackrel{d}{\longrightarrow} N(0,1)$ <br> 且 $\sum_{i=1}^{n} X_i \stackrel{\text{近似}}{\sim} N(n\mu, n\sigma^2)$ | 无论总体是什么分布，只要独立同分布且方差存在，当 $n$ 充分大时，**样本和**或**样本均值**的标准化形式就近似服从标准正态分布。这是最常用的中心极限定理。             |
| **棣莫弗-拉普拉斯定理** | $Y_n \sim B(n, p)$，即 $Y_n$ 是 $n$ 重伯努利试验中成功的次数。 | $\lim_{n \to \infty} P\left( \frac{Y_n - np}{\sqrt{np(1-p)}} \le x \right) = \Phi(x)$ <br> 即：$Y_n \stackrel{\text{近似}}{\sim} N(np, np(1-p))$                                                                                                                            | 这是**同分布中心极限定理在二项分布上的特例**（其中 $X_i \sim B(1, p)$）。当 $n$ 很大时，可以用正态分布来近似计算二项分布的概率，提供了二项分布的近似计算方法。 |

## 常用统计量的分布

| 分布名称                    | 定义/构成                                                                                                                                                                                | 概率密度图像特点                                                    | 主要性质/用途                                                                                                        |
| :---------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------- |
| **样本线性函数**<br>(正态总体)    | 设 $X_1, ..., X_n \stackrel{i.i.d.}{\sim} N(\mu, \sigma^2)$，则：<br>1. $\bar{X} \sim N(\mu, \frac{\sigma^2}{n})$<br>2. $\sum_{i=1}^{n} a_i X_i \sim N(\mu\sum a_i, \sigma^2\sum a_i^2)$ | 正态曲线                                                        | **样本均值和样本的线性组合仍服从正态分布**，这是正态总体的重要特性。                                                                           |
| **卡方分布**<br>$\chi^2(n)$ | $X_1, ..., X_n \stackrel{i.i.d.}{\sim} N(0,1)$，则 $Y = \sum_{i=1}^{n} X_i^2 \sim \chi^2(n)$。<br>**自由度** $n$ 为平方项个数。                                                                   | 非负、右偏。<br>随 $n$ 增大，分布渐近对称。                                  | 1. **可加性**：若 $U \sim \chi^2(m)$，$V \sim \chi^2(n)$ 且独立，则 $U+V \sim \chi^2(m+n)$。<br>2. 用于**方差估计**、**拟合优度检验**等。 |
| **t 分布**<br>$t(n)$      | 若 $X \sim N(0,1)$，$Y \sim \chi^2(n)$，且 $X$ 与 $Y$ 独立，则 $T = \frac{X}{\sqrt{Y/n}} \sim t(n)$。<br>**自由度** $n$。                                                                          | 对称、钟形，比标准正态更扁平、尾部更厚。<br>$n \to \infty$ 时，$t(n) \to N(0,1)$。 | 主要用于**小样本下总体均值的推断**（$\sigma$ 未知时）。<br>$t(1)$ 为柯西分布，无期望。                                                        |
| **F 分布**<br>$F(m, n)$   | 若 $U \sim \chi^2(m)$，$V \sim \chi^2(n)$，且独立，则 $F = \frac{U/m}{V/n} \sim F(m, n)$。<br>**自由度** $m$（分子）、$n$（分母）。                                                                        | 非负、右偏。<br>形状由两个自由度决定。                                       | 1. 与 $t$ 分布关系：$t^2(n) = F(1, n)$。<br>2. 主要用于**两总体方差的比较**（方差比检验）、**方差分析 (ANOVA)**。                              |

## 点估计

### 点估计的两种方法

注意，以下关键步骤仅为常规套路，并不保证所有题目都可以用该套路解决。

| 估计方法        | 关键步骤                                                                                                                                                                                                                                                                                                                                                                               |
| :---------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **矩估计法**    | 1. 列出总体矩（通常是前 $k$ 阶原点矩）：$\mu_l = E(X^l) = g_l(\theta_1, ..., \theta_k)$<br><br>2. 列出对应的样本矩：$A_l = \frac{1}{n}\sum_{i=1}^{n} X_i^l$<br><br>3. **令总体矩等于样本矩**，解方程组：<br> $g_l(\hat{\theta}_1, ..., \hat{\theta}_k) = A_l, \quad l=1,2,...,k$                                                                                                                                           |
| **极大似然估计法** | 1. 写出**似然函数**：<br> &nbsp;&nbsp;- 离散： $L(\theta) = \prod_{i=1}^{n} P(X = x_i; \theta)$<br> &nbsp;&nbsp;- 连续： $L(\theta) = \prod_{i=1}^{n} f(x_i; \theta)$<br> <br>2. 取对数（常简化为对数似然函数）： $\ln L(\theta)$<br><br>3. 对参数 $\theta$ 求导（或求偏导），**令导数为零**：<br> $\frac{\partial \ln L(\theta)}{\partial \theta_j} = 0, \quad j=1,...,k$<br> <br>4. 解此似然方程组，得到**极大似然估计量 $\hat{\theta}_{MLE}$**。 |
### 点估计的优良性

| 估计量性质        | 核心定义与公式                                                                                                                                                                                                                                                                                    |
| :----------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **无偏估计**     | 如果估计量 $\hat{\theta}$ 的期望等于参数真值 $\theta$：<br>$E(\hat{\theta}) = \theta$                                                                                                                                                                                                                     |
| **最小方差无偏估计** | 在参数 $\theta$ 的所有无偏估计量组成的类 $\mathcal{U}$ 中，若 $\hat{\theta}^*$ 满足：<br>$Var(\hat{\theta}^*) \le Var(\hat{\theta}), \quad \forall \hat{\theta} \in \mathcal{U}$                                                                                                                                |
| **一致估计**     | 若估计量 $\hat{\theta}_n$ 依概率收敛于参数真值 $\theta$：<br>$\lim_{n \to \infty} P( \mid \hat{\theta}_n - \theta \mid < \varepsilon ) = 1, \quad \forall \varepsilon > 0$<br><br>充分条件：$\lim_{n \to \infty} E(\hat{\theta}_n) = \theta$ 且 $\lim_{n \to \infty} Var(\hat{\theta}_n) = 0$<br>（即渐近无偏且方差趋于零）。 |

## 数字特征

| 函数名称       | 核心定义（对随机过程 $\{X(t)\}$）                                                        | 常用计算形式（考试重点）                                                                                   |
| :--------- | :---------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------- |
| **均值函数**   | $m_X(t) = E[X(t)]$ 【!】                                                        | $m_X(t) = \int_{-\infty}^{\infty} x f_t(x) dx$                                                 |
| **均方值函数**  | $\Psi_X^2(t) = E[X^2(t)]$ 【!】                                                 | $\Psi_X^2(t) = \int_{-\infty}^{\infty} x^2 f_t(x) dx$ <br> 或 $D[X(t)] + [m_X(t)]^2$            |
| **方差函数**   | $\sigma_X^2(t) = D[X(t)] = E\{[X(t)-m_X(t)]^2\}$                              | $\sigma_X^2(t) = E[X^2(t)] - [E(X(t))]^2$ 【!】<br><br> 或 $\sigma_X^2(t) = R_X(t, t) - m_X(t)^2$ |
| **自相关函数**  | $R_X(s, t) = E[X(s)X(t)]$ 【!】                                                 | $R_X(s, t) = \iint xy f_{s,t}(x,y) dxdy$                                                       |
| **自协方差函数** | $C_X(s, t) = \text{Cov}[X(s), X(t)]$ <br> $= E\{[X(s)-m_X(s)][X(t)-m_X(t)]\}$ | $C_X(s, t) = R_X(s, t) - m_X(s)m_X(t)$ 【!】                                                     |

## 判断广义平稳过程

| 判断步骤                | 具体条件与操作                                                                                                    |
| :------------------ | :--------------------------------------------------------------------------------------------------------- |
| **第一步：判断均值是否平稳**    | 计算均值函数 $m_X(t) = E[X(t)]$，检查其是否为常数 $m$，即 $m_X(t) = m$（与时间 $t$ 无关）。                                         |
| **第二步：判断自相关函数是否平稳** | 计算自相关函数 $R_X(s, t) = E[X(s)X(t)]$，检查其是否仅依赖于时间差 $\tau = t - s$，即 $R_X(s, t) = R_X(\tau)$（与 $s, t$ 的绝对位置无关）。 |
