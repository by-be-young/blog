# 递归方程解法

预备知识：

| 符号                    | 直观意义（类似算术比较）  | 口语解释              |
| --------------------- | ------------- | ----------------- |
| $f(n) = O(g(n))$      | $f \le g$（上界） | “f 不超过 g 的常数倍”    |
| $f(n) = \Omega(g(n))$ | $f \ge g$（下界） | “f 至少是 g 的常数倍”    |
| $f(n) = \Theta(g(n))$ | $f = g$（紧确界）  | “f 与 g 同阶，常数倍内相等” |
| $f(n) = o(g(n))$      | $f < g$（严格小于） | “f 比 g 增长慢得多”     |
| $f(n) = \omega(g(n))$ | $f > g$（严格大于） | “f 比 g 增长快得多”     |

---

## 一、主定理

#### 对于 $T(n) = aT\left(\frac{n}{b}\right) + f(n)$，其中 $a \geq 1, b > 1$：

| 比较 $f(n)$ 与 $n^{\log_b a}$ | 条件                                                                                                             | 解 $T(n)$                            |
| -------------------------- | -------------------------------------------------------------------------------------------------------------- | ----------------------------------- |
| $f(n)$ 多项式更小               | $f(n) = O(n^{\log_b a - \varepsilon}), \varepsilon > 0$                                                        | $\Theta(n^{\log_b a})$              |
| $f(n)$ 同阶（带 log 因子）        | $f(n) = \Theta(n^{\log_b a} \log^k n), k \geq 0$                                                               | $\Theta(n^{\log_b a} \log^{k+1} n)$ |
| $f(n)$ 多项式更大且正则            | $f(n) = \Omega(n^{\log_b a + \varepsilon}), \varepsilon > 0$<br>且 $af\left(\frac{n}{b}\right) \leq cf(n), c<1$ | $\Theta(f(n))$                      |

## 二、常见递归式速查表

| 递归式                                                    | 解                                                |
| ------------------------------------------------------ | ------------------------------------------------ |
| $T(n) = T\left(\frac{n}{2}\right) + O(1)$              | $\Theta(\log n)$                                 |
| $T(n) = 2T\left(\frac{n}{2}\right) + O(1)$             | $\Theta(n)$                                      |
| $T(n) = 2T\left(\frac{n}{2}\right) + \Theta(n)$        | $\Theta(n \log n)$                               |
| $T(n) = 2T\left(\frac{n}{2}\right) + \Theta(n \log n)$ | $\Theta(n \log^2 n)$                             |
| $T(n) = 2T\left(\frac{n}{2}\right) + \Theta(n^2)$      | $\Theta(n^2)$                                    |
| $T(n) = 3T\left(\frac{n}{2}\right) + \Theta(n)$        | $\Theta(n^{\log_2 3}) \approx \Theta(n^{1.585})$ |
| $T(n) = 4T\left(\frac{n}{2}\right) + \Theta(n)$        | $\Theta(n^2)$                                    |
| $T(n) = 4T\left(\frac{n}{2}\right) + \Theta(n^2)$      | $\Theta(n^2 \log n)$                             |
| $T(n) = 7T\left(\frac{n}{2}\right) + \Theta(n^2)$      | $\Theta(n^{\log_2 7}) \approx \Theta(n^{2.807})$ |
| $T(n) = T(n-1) + \Theta(1)$                            | $\Theta(n)$                                      |
| $T(n) = T(n-1) + \Theta(n)$                            | $\Theta(n^2)$                                    |
| $T(n) = 2T(n-1) + \Theta(1)$                           | $\Theta(2^n)$                                    |
| $T(n) = T(\sqrt{n}) + \Theta(1)$                       | $\Theta(\log \log n)$                            |
| $T(n) = T(\sqrt{n}) + \Theta(\log n)$                  | $\Theta(\log n)$                                 |

## 三、特殊形式（主定理不适用时常用结论）

| 形式                                                                          | 解（假设足够正则）                                                      |
| --------------------------------------------------------------------------- | -------------------------------------------------------------- |
| $T(n) = aT\left(\frac{n}{b}\right) + \Theta(n^{\log_b a} \log^k n)$         | $\Theta(n^{\log_b a} \log^{k+1} n)$                            |
| $T(n) = T(\alpha n) + T((1-\alpha)n) + \Theta(n), 0<\alpha<1$               | $\Theta(n \log n)$                                             |
| $T(n) = T\left(\frac{n}{3}\right) + T\left(\frac{2n}{3}\right) + \Theta(n)$ | $\Theta(n \log n)$                                             |
| $T(n) = \sqrt{n} T(\sqrt{n}) + \Theta(n)$                                   | $\Theta(n \log \log n)$                                        |
| **$T(n) = T(n-1) + T(n-2)$（Fibonacci 型）**                                   | **$\Theta(\phi^n)$，其中 $\phi = \frac{1+\sqrt{5}}{2}$**（约 1.618） |
