# 第一章 中国国防

## 第一节 国防概述

### 国防的内涵

- **国防**是指国家为防备和抵抗侵略，制止武装颠覆和分裂，保卫国家的**主权、统一、领土完整和安全**所进行的军事活动，以及与军事有关的政治、经济、外交、科技、教育等方面的活动。
- 国防的行为主体是国家，基本内容包括**国防建设**和**国防斗争**两个方面。
- 国防的地位作用：
  1. 是国家**生存与发展**的安全保障。
  2. 是国家**独立自主**的前提。
  3. 是国家**繁荣富强**的重要条件。

### 国防类型

- 按表现形式分为**扩张型**和**自卫型**：
  1. **扩张型**：奉行霸权主义、强权政治和进攻型战略。
  2. **自卫型**：以维护国家安全、防止和抵御外敌侵略为目的。
- 中国属于**自卫型**国防。

### 国防历史与启示

- 中国古代最早的国防起源于**夏朝**。
- 中国现代国防具有鲜明特点：
  1. **政治性**：服从中国共产党的绝对领导，服从党和国家总路线、总政策，服务于国家总体战略目标。
  2. **防御性**
  3. **人民性**
  4. **自主性**
- 国防历史的启示：
  1. **政治昌明**是国防巩固的根本。
  2. **经济发展**是国防强大的基础（物质基础）。
  3. **国家统一和民族团结**是国防强大的前提。

### 现代国防观

- 我国奉行**防御性国防政策**，但其时代内涵随安全形势和国防需求变化而拓展：
  1. **范围拓展**：生存安全与发展安全、传统安全与非传统安全交织，维护发展利益任务艰巨。
  2. **目标拓展**：从打赢战争到遏制战争，从争取和平到维护和平，维护国家和平发展和世界和平成为基本目标。
  3. **任务拓展**：巩固内部安全与防范外来威胁统一，应对传统与非传统挑战统一，提高多样化军事任务能力。
  4. **手段拓展**：在打赢信息化局部战争基础上，增强军事手段主动性，配合政治、经济、外交、文化、法律等手段，实现综合安全。

## 第二节 国防法规

### 国防法规体系

- **国防法规体系**是指国家和军队现行国防法律规范按照**层次和门类**构成的有机整体。
- 主要国防法规包括：
  1. **《中华人民共和国国防法》**——基本法律依据
  2. **《中华人民共和国兵役法》**
  3. **《中华人民共和国国防教育法》**
  4. **《中华人民共和国国防动员法》**
  5. **《中华人民共和国人民防空法》**
  6. **《中华人民共和国军事设施保护法》**
  7. **《中华人民共和国预备役人员法》**
  8. **《中国人民解放军文职人员条例》**

### 公民的国防义务和权利

- 公民的国防义务包括：
  1. 履行**兵役**的义务。
  2. 接受**国防教育**的义务。
  3. 保护**国防设施**的义务。
  4. 保守**国防秘密**的义务。
  5. 协助**国防活动**的义务。
- 兵役义务的具体规定：
  1. 兵役分为**现役**和**预备役**。
  2. 年满 **18** 岁的男性公民应被征集服现役，当年未被征集的，在 **22** 岁前仍可被征集。
  3. 普通高等学校毕业生征集年龄放宽到 **24** 周岁，研究生放宽到 **26** 周岁。
- 接受国防教育的义务：**《国防教育法》第 15 条**规定，高等学校、高级中学等应将课堂教育与军事训练相结合，高等学校应设置国防教育课程。
- 公民的国防权利包括：
  1. 对国防建设提出**建议**的权利。
  2. 对危害国防行为进行**制止或检举**的权利。
  3. 获得**经济损失补偿**的权利。
- 国防义务与权利的关系：**对立统一**。

## 第三节 国防建设

### 国防体制

- **全国人大常委会**决定全国总动员或局部动员。
- **国家主席**根据全国人大常委会决定发布动员令。
- **国务院、中央军委**共同领导全国国防动员工作。

### 国防战略

- **国防战略**是筹划和指导国防建设与斗争全局的方略，受国家战略指导和制约。
- 国防战略的任务包括：
1. 决定**国防力量**的建设和发展。
2. 指导**国防斗争**的实施。
3. 维护**国家安全**利益。
- 我国坚持**积极防御**战略思想，由社会主义性质、国家根本利益和和平发展道路决定。

### 国防政策

- 我国奉行**防御性国防政策**，由社会主义国家性质、和平发展战略、独立自主和平外交政策和“和为贵”文化传统决定。
- 贯彻新时代军事战略方针，坚持**防御、自卫、后发制人**原则，实行积极防御，强调“**人不犯我、我不犯人，人若犯我、我必犯人**”，以及**遏制战争与打赢战争相统一**、**战略上防御与战役战斗上进攻相统一**。

## 第四节 武装力量

### 中国武装力量的性质、宗旨

- 中国共产党是无产阶级政党，是工人阶级、中国人民和中华民族的先锋队，是中国特色社会主义事业领导核心，代表各族人民根本利益。
- 由党缔造和领导的人民军队必须保持**人民军队**性质，忠于党、忠于社会主义、忠于祖国、忠于人民，确保**绝对忠诚、绝对纯洁、绝对可靠**。

### 中国武装力量的使命任务

- 新时代的使命任务包括：
  1. 为巩固**中国共产党领导和社会主义制度**提供战略支撑。
  2. 为捍卫**国家主权、统一、领土完整**提供战略支撑。
  3. 为维护**国家海外利益**提供战略支撑。
  4. 为促进**世界和平与发展**提供战略支撑。
- 具体任务包括：
  1. 维护国家**领土主权和海洋权益**。
  2. 保持**常备不懈**的战备状态。
  3. 开展**实战化**军事训练。
  4. 维护**重大安全领域**利益。
  5. 进行**反恐维稳**。
  6. 维护**海外利益**。
  7. 参加**抢险救灾**。

### 中国武装力量构成

- 由**中国人民解放军**、**中国人民武装警察部队**、**民兵**组成。
- **民兵**是**不脱离生产**的群众武装组织，是武装力量的组成部分，是助手和后备力量。

## 第五节 国防动员

### 国防动员概述

- 定义：**国防动员**是指国家为应对战争或其他安全威胁，使社会诸领域全部或部分由平时状态转入战时状态或紧急状态的活动。
- 主要内容包括：
  1. **武装力量动员**
  2. **国民经济动员**
  3. **人民防空动员**
  4. **交通战备动员**
  5. **政治动员**
- 政治动员：
  1. 平时主要表现为**国防教育**。
  2. 战时包括**国内政治动员**和**外交舆论宣传**。

# 第四章 现代战争

## 战争的内涵

- 从政治层面看：战争是**政治的继续**，是社会政治矛盾极端尖锐化的暴力斗争。
- 从经济层面看：战争是政治的继续，而政治是经济的集中体现，战争与一定经济基础和条件密切联系。
- 从军事层面看：各种战争的本质都是**保存自己、消灭敌人**。

## 战争的基本特点

- **激烈的暴力对抗**。
- **快速地流动变化**。
- **充满盖然性或偶然性**。

## 新军事革命

- 定义：**20 世纪末**以来在世界范围内发生的一场以**信息化**为核心的全面而深刻的军事革命。
- 主要标志：
  1. **信息化武器系统**逐渐主宰战场。
  2. 出现**知识密集型**的信息化军队。
  3. **一体化联合作战**成为基本作战形式。
  4. **军事理论**及其体系彻底革新。
  5. **信息化战争**最终取代机械化战争。

## 中国特色军事变革

- 发展方向：**信息化**。
- 基本目标：建设**信息化军队**。
- 基本途径：**机械化与信息化的复合发展**。
- 发展步骤：与国家发展战略相适应。
- 根本行动：**改革创新**。
- 根本保证：坚持**中国共产党的绝对领导**。

## 机械化战争

- 基本特征：
  1. **机动速度快**。
  2. **火力毁伤重**。
  3. **战场范围广**。
  4. **战争消耗大**。

## 信息化战争

- 定义：**信息化战争**是依托网络化信息系统，使用信息化武器装备及相应作战方法，在陆、海、空、天和网络电磁等空间及认知领域进行的以**体系对抗**为主要形式的战争，是信息时代战争的基本形态。
- 基本特征：
  1. **信息化武器装备系统**成为战场主导。
  2. **信息**成为战斗力的倍增器。
  3. **战场网络化、一体化**。
  4. **一体化联合作战**成为基本作战形式。
  5. **制信息权**成为争夺的制高点。

# 第五章 信息化装备

## 信息化装备概述

- 按功能分为**信息化主战武器系统**和**信息系统**两大类。
- 从作战体系角度细分为：
  1. **信息化作战平台**（陆战、海战、空战平台，空战平台包括战斗机、轰炸机、电子战飞机、运输机等）。
  2. **指挥信息系统**。
  3. **信息化杀伤武器**。

## 指挥信息系统

- 定义：**指挥信息系统**是以计算机网络为核心，由指挥控制、情报、通信、信息对抗、综合保障等分系统组成，对作战信息进行实时获取、传输、处理，保障各级指挥机构实施科学高效指挥控制的军事信息系统。
- 重要分系统包括：
  1. **指挥控制系统**
  2. **情报系统**
  3. **通信系统**
  4. **导航定位系统**

## 信息化杀伤武器

- 新概念武器包括：
  1. **激光技术**和**激光武器**
  2. **微波武器**
  3. **粒子束武器**
  4. **动能武器**
  5. **非致命武器**
