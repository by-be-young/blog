# 一、封装（Encapsulation）

### 访问权限 - protected
1. 包内可见。
2. 对子类可见：
   - 子类和父类在同一个包：通过自己或父类访问。
   - 在不同包：仅可通过自己访问。
1. **protected static 成员对所有子类可见**。

---

# 二、static 关键字

### 静态成员变量
类加载时装载，通过 `类名.变量名` 访问。

### 静态成员方法
通过 `类名.方法名` 调用，只能访问静态成员。

### 静态代码块
用于初始化静态变量，仅定义在类中。

### 语句执行顺序

#### 第一次 new 时：
1. 初始化有显式初始化的静态成员变量。
2. 执行静态代码块。
3. 初始化有显式初始化的非静态成员变量。
4. 执行非静态代码块。
5. 调用构造方法。

#### 后续 new 时：
1. 初始化有显式初始化的非静态成员变量。
2. 执行非静态代码块。
3. 调用构造方法。

# 三、内部类

### 特点
能访问外部类的所有成员。

### 类型

#### 实例内部类
外部类实例必须已存在。

#### 静态内部类
创建时不需外部类实例。

#### 局部内部类
仅在方法中使用，可访问外部类成员及方法中的 `final` 变量。

# 四、equals 与==

### 对象的 equals 与==
默认等价，判断是否为同一对象。

### String 的 equals
重写了 Object 的 equals，只比较内容；==比较是否为同一对象。

# 五、方法重载（Overload）

### 规则
同名方法，参数列表必须不同（个数、类型、顺序）。

### 注意
返回值类型和访问修饰符可相同也可不同，**不能作为重载判断依据**。

---

# 六、继承（Inheritance）

### 基本特性
子类拥有父类所有属性和方法（私有除外）。

### 构造方法
构造方法不能继承，子类构造必须先调用父类构造。

### 变量隐藏
子类隐藏父类同名变量。

---

## Super vs this

### 共性
1. 出现在实例方法和构造方法中。
2. 不能出现在静态方法中。
3. 大部分情况可省略。
4. `this()`、`super()` 只能在构造方法第一行。

### Super
用于访问父类成员；调用父类构造方法。

---

# 七、方法重写/覆盖（Override）

### 条件
1. 返回值相同或是其子类。
2. 方法名、形参列表完全相同。
3. 访问权限不能更低（只能相同或更高）。
4. 抛出异常范围不能更大。

### 注意事项
1. `private` 方法不能覆盖（只能隐藏）。
2. 构造方法不能覆盖。
3. 静态方法不存在覆盖（只有隐藏）。
4. `final` 方法不能覆盖。

---

# 八、多态（Polymorphism）

### 静多态
编译时，如方法重载。

### 动多态
运行时，需满足：继承、覆盖、向上转型。

### 成员变量
编译运行看左边。

### 成员方法
编译看左边，运行看右边。

### 向上转型（upcasting）
父类引用管理子类对象。

### 向下转型（downcasting）
需使用强制转换，可能存在风险，建议用 `instanceof` 判断。

---

# 九、抽象类与接口

### 抽象类（abstract）
1. 含抽象方法的类必须声明为抽象类。
2. 不能实例化。
3. 抽象方法无函数体，必须在子类中实现（除非子类也是抽象类）。
4. 不能被 `private`、`final`、`static` 修饰。

### 接口（interface）
1. 方法默认 `public abstract`，变量默认 `public static final`。
2. 无构造方法。
3. 支持多继承，接口回调机制。

### 不可变性
`final` 修饰，修改即创建新对象。

### 字符串比较
`equals()` 比较内容，`==` 比较地址。

# 十二、构造方法与垃圾回收

### 构造方法
与类同名，无返回值，可重载。

### New 的作用
分配空间、调用构造、返回引用。

### 垃圾回收（GC）
引用计数为 0 时回收。

### 匿名对象
无引用指向，适用于一次性调用或参数传递。

---

# 十三、多线程与同步

### Wait、notify、notifyAll
必须在 `synchronized` 方法或块中调用。

### Wait
释放锁，进入等待队列。

### Notify
随机唤醒一个等待线程。

### NotifyAll
唤醒所有等待线程。

---

# 十四、单例模式

### 饿汉式
类加载时初始化，线程安全，但可能浪费内存。

### 懒汉式
第一次使用时初始化，线程不安全（需加锁）。

### 常见考题
懒汉式在第一次使用时构建，饿汉式在类加载时构建。

---
