意大利语被誉为“世界上最美丽的语言”之一，最大的特点就是“所见即所读”。

由于我只是为了学习美声课中的歌曲唱法，对于意大利语我暂时没有兴趣过多涉猎语法，因此学习自然拼读已经绰绰有余了。

好在意大利语的自然拼读特别管用，比破英语好多了。开心~

# 元音

元音共有五个：a, e, i, o, u

非常之简单，因为元音完全没有多音！

发音也很简单，读音类似日语但嘴型饱满度类似中文，无需多言。

# 单辅音

## 清辅音与浊辅音

意大利语的清辅音和浊辅音的发音及区别和日语几乎一致，即通过声带是否振动来区分。与中文和英语不一样。

简单来说，比如 p 也发类似 b 的音，但是声带不振动。有点抽象，但是你可以理解为浊辅音声音比较重一点，或者是比较浑厚一点？

## H

H 不发音！网上不是流传了什么笑话，说意大利人笑都是啊啊啊的笑而不是哈哈哈。啊啊啊啊啊。

一开始我还不理解为什么不发音还要有这个字母，但是学到后面就柳暗花明了。

## C

| 拼写       | 音标   | 例子                 |
| -------- | ---- | ------------------ |
| 后接 a，o，u | /k/  | **casa** /ˈka.za/  |
| 后接 e，i   | /tʃ/ | **cena** /ˈtʃe.na/ |
| 后接 h     | /k/  | **che** /ke/       |
也就是说，h 把 c 和 e 或 i 隔开了，这让 c 的发音改变了！是一个不错的记号。

（英语什么时候能够有这种变音记号）

## G

| 拼写       | 音标   | 例子                     |
| -------- | ---- | ---------------------- |
| 后接 a，o，u | /g/  | **gatto** /ˈgat.to/    |
| 后接 e，i   | /dʒ/ | **gelato** /dʒeˈla.to/ |
| 后接 h     | /g/  | **laghi** /ˈla.gi/     |
和 C 的发音方式简直如出一辙。

## S

一般情况下或形成双辅音时，发清辅音；

在两个元音之间或在其他浊辅音之前时，发浊辅音。

## Z

可恶，这是意大利语中唯一一个没有发音规则的字母!! 罪大恶极！

清辅音发/ts/，浊辅音发/dz/

不过好在，既然清辅音和浊辅音发音差别不大，就按浊辅音的发音来发就好了，我赌你听不出来。

## R

rrrrrrrrrrrrr~~~~~

震撼中国人一百年的大舌颤音粉墨登场！

很好笑的是，如果单让我发这个音，我完全发不出来，但是放进单词里，就很自然地就发出来了。很奇怪。

不过这个弹舌不要求时长很长，随便弹两下就够了，再让我发长一点时间就变成故里呱啦的了 ww

# 双辅音

## 简单双辅音

把同一个辅音写两遍就是简单双辅音。

学过日语的有福了，就和日语的促音完全一致！伟大！

一句话概括就是，在发这个辅音之前空半拍即可。

## 特殊双辅音：gn

就像是把“你”这个字“挤出来”的一样，听感上甚至有点咖喱味（）

除去这个特殊的味道之外，和日语に行的拗音特别像。比如 gna 就像是にゃ（nya）。

## 特殊双辅音：gl

#### 注意，只有跟元音 i 的时候才发以下的音，否则就正常发。

这个发音好难受啊，至少我学过的几门语言中完全没有类似的音哇！

发音大概是：你想发 l 音，但是舌尖往下卷（）

真是个搞笑的发音！

## 特殊双辅音：sc

#### 注意，只有跟元音 e 或 i 时才发以下的音，否则就正常发。

非常简单，就发/ʃ/的音。

但是由于 sc 和 sh 与英语中的发音几乎正好相反，很容易搞混啊！

## 特殊双辅音：cq

把它当作 qq 即可。意大利语中大概没有单词有 qq 连用，而是用 cq 代替，发音规则与简单双辅音一致（即类似促音）。
