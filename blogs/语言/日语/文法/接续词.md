# 词汇整理

## 顺接

| 词汇        | 含义 / 语感               |
| --------- | --------------------- |
| **だから**   | 所以、因此（较随意、主观）         |
| **ですから**  | 所以、因此（だから的礼貌形）        |
| **それで**   | 因此、所以（口语，客观陈述经过）      |
| **したがって** | 因而、因此（书面，客观推论）        |
| **そこで**   | 于是、因此（针对前文状况**采取行动**） |
| **すると**   | 于是、那么（前项刚发生，后项紧接着发生）  |

## 逆接 

|词汇|含义 / 语感|
|---|---|
|**しかし**|但是（书面、正式，强转折）|
|**でも**|可是、不过（口语，缓和反驳）|
|**けれども**|虽然……但是（书面礼貌，亦作铺垫）|
|**けど**|虽然……但是（けれども的口语缩略）|
|**だが**|但是（书面简体，论文常用）|
|**ところが**|然而、可是（后常接**意外/消极**结果）|
|**それなのに**|尽管那样、却（含有不满、遗憾语气）|

## 并列、添加

|词汇|含义 / 语感|
|---|---|
|**そして**|而且、然后、接着（时间先后或并列）|
|**それから**|然后、还有（侧重动作先后顺序）|
|**また**|又、还、再（并列同类事物）|
|**それに**|而且、再加上（客观追加理由）|
|**そのうえ**|加之、而且（有“雪上加霜”或锦上添花感）|
|**しかも**|而且、并且（强调程度超出预期）|

## 选择

|词汇|含义 / 语感|
|---|---|
|**それとも**|还是（**疑问句**二选一专用）|
|**または**|或者（陈述句，并列选项）|
|**あるいは**|或者、或是（语气比または柔和）|

## 说明

|词汇|含义 / 语感|
|---|---|
|**つまり**|也就是说、即（换一种说法概括）|
|**すなわち**|即、即是（书面，定义说明）|
|**要するに**|总之、简而言之（不耐烦或强调核心）|
|**なぜなら**|因为、原因是（后接**解释理由**的完整句）|
|**ただし**|不过、但（补充**例外条件或限制**）|
|**ちなみに**|顺便一提、附带说一句（离题小补充）|

## 转换

|词汇|含义 / 语感|
|---|---|
|**ところで**|话说回来、对了（突然转换话题）|
|**さて**|那么、且说（正式进入正题）|
|**では / それでは**|那么、那样的话（以此为条件推进）|

# 例题

[task]
[question]
もうすぐ今年も終わりますね、（）お正月は故郷へ帰るんですか？
[\question]
[options]A　まず[\options]
[options]B　もう[\options]
[options]C　ところが[\options]
[options]D　ところで[\options]
[answer]D[\answer]
[analysis]
「もうすぐ今年も終わりますね」用于寒暄，提示一年即将结束；「お正月は故郷へ帰るんですか」询问对方正月是否回老家。前后话题从“年末”转移到“正月安排”，需要表示转换话题的接续词。「ところで」正是用于转换话题的表达，意为“话说”“对了”。

「まず」是副词，表示“首先”，「もう」也是副词，表示“已经”或“再”，「ところが」是接续词，表示转折（然而），均不符合此处语境。[\analysis]
[\task]
