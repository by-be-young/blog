# 递归方程解法

预备知识：

| 符号                    | 直观意义（类似算术比较）  | 口语解释              |
| --------------------- | ------------- | ----------------- |
| $f(n) = O(g(n))$      | $f \le g$（上界） | “f 不超过 g 的常数倍”    |
| $f(n) = \Omega(g(n))$ | $f \ge g$（下界） | “f 至少是 g 的常数倍”    |
| $f(n) = \Theta(g(n))$ | $f = g$（紧确界）  | “f 与 g 同阶，常数倍内相等” |
| $f(n) = o(g(n))$      | $f < g$（严格小于） | “f 比 g 增长慢得多”     |
| $f(n) = \omega(g(n))$ | $f > g$（严格大于） | “f 比 g 增长快得多”     |

## 主定理

#### 对于 $T(n) = aT\left(\frac{n}{b}\right) + f(n)$，其中 $a \geq 1, b > 1$：

| 比较 $f(n)$ 与 $n^{\log_b a}$ | 条件                                                                                                             | 解 $T(n)$                            |
| -------------------------- | -------------------------------------------------------------------------------------------------------------- | ----------------------------------- |
| $f(n)$ 多项式更小               | $f(n) = O(n^{\log_b a - \varepsilon}), \varepsilon > 0$                                                        | $\Theta(n^{\log_b a})$              |
| $f(n)$ 同阶（带 log 因子）        | $f(n) = \Theta(n^{\log_b a} \log^k n), k \geq 0$                                                               | $\Theta(n^{\log_b a} \log^{k+1} n)$ |
| $f(n)$ 多项式更大且正则            | $f(n) = \Omega(n^{\log_b a + \varepsilon}), \varepsilon > 0$<br>且 $af\left(\frac{n}{b}\right) \leq cf(n), c<1$ | $\Theta(f(n))$                      |

# 排序算法

## 各种排序方法一览表

| 算法       | 平均时间复杂度       | 最坏时间复杂度       | 空间复杂度       | 稳定性 | 原地排序* | 主要特点                 |
| -------- | ------------- | ------------- | ----------- | --- | ----- | -------------------- |
| **冒泡排序** | $O(n^2)$      | $O(n^2)$      | $O(1)$      | ✓   | ✓     | 简单，效率低，稳定            |
| **选择排序** | $O(n^2)$      | $O(n^2)$      | $O(1)$      | ✗   | ✓     | 交换次数少，不稳定            |
| **插入排序** | $O(n^2)$      | $O(n^2)$      | $O(1)$      | ✓   | ✓     | 小规模/基本有序数据高效         |
| **快速排序** | $O(n \log n)$ | $O(n^2)$      | $O(\log n)$ | ✗   | ✓     | 实际应用快，原地，分治          |
| **归并排序** | $O(n \log n)$ | $O(n \log n)$ | $O(n)$      | ✓   | ✗     | 稳定，分治，适合外排序          |
| **堆排序**  | $O(n \log n)$ | $O(n \log n)$ | $O(1)$      | ✗   | ✓     | 原地 $O(n \log n)$，不稳定 |
| **桶排序**  | $O(n + k)$    | $O(n^2)$      | $O(n + k)$  | ✓*  | ✗     | 数据均匀分布，$k$ 为桶数       |
| **计数排序** | $O(n + k)$    | $O(n + k)$    | $O(n + k)$  | ✓   | ✗     | 整数，值域 $k$ 小          |
| **基数排序** | $O(d(n + k))$ | $O(d(n + k))$ | $O(n + k)$  | ✓   | ✗     | 多关键字，$d$ 为位数         |

*原地排序：不需要额外开辟空间来排序。

*桶排序的稳定性取决于桶内使用的排序算法。

## 桶排序和快速排序的比较

| 条件        | 桶排序更优         | 快速排序更优         |
| --------- | ------------- | -------------- |
| **数据分布**  | 均匀分布          | 倾斜/未知分布        |
| **值域范围**  | 有限且较小         | 范围大或未知         |
| **数据量**   | 大规模($n>10^5$) | 小中规模($n<10^4$) |
| **内存**    | 充足            | 紧张             |
| **稳定性需求** | 需要稳定排序        | 不需要稳定          |
# 摊还分析（平摊分析）

## 基本概念
- **定义**：分析**一系列操作**的平均时间上界，为每个操作赋予平摊成本
- **核心思想**：昂贵操作的发生频率足够低，均摊到整个序列后成本很低
- **与平均情况分析的区别**：
  - 平摊分析：**最坏情况下的操作序列**的平均性能
  - 平均情况：基于**概率分布**的期望性能

## 三种分析方法

### 1. 聚集分析
- **思路**：计算 $n$ 个操作的总成本 $T(n)$，则平摊成本为 $T(n)/n$
- **特点**：简单直观，但有时难以精确计算总成本
- **示例**：动态数组插入
  - 最坏单次：$O(n)$（扩容）
  - $n$ 次插入总成本：$T(n) ≤ 2n$（每次插入摊 1 元，扩容复制摊 1 元）
  - 平摊成本：$O(1)$

### 2. 记账法/核算法
- **思路**：为每个操作分配"费用"
  - **实际费用**：操作的真实成本，称为“实际代价”
  - **分配费用**：收取的平摊成本，称为“摊还代价”
  - 要求：任何时刻 $\sum \text{分配费用} ≥ \sum \text{实际费用}$
- **信用**：分配费用 > 实际费用时产生"信用"，用于补贴未来昂贵操作
- **示例**：动态数组插入
  - 分配费用：3 元
  - 实际费用：1 元（普通插入）或 $k+1$ 元（扩容，$k$ 为旧数组大小）
  - 检查：每次普通插入剩余 2 元信用，扩容时信用足够支付复制成本

### 3. 势能法
- **思路**：
  - 定义**势能函数**$\Phi(D_i)$，表示数据结构 $D$ 在第 $i$ 次操作后的"势能"
  - 平摊成本 = 实际成本 + 势能变化
    $$c_i' = c_i + \Phi(D_i) - \Phi(D_{i-1})$$
  - 要求：$\Phi(D_0) = 0$，且 $\Phi(D_i) ≥ 0$（始终非负）
- **势能函数意义**：度量数据结构的"混乱程度"或"预存储的能量"
- **示例**：动态数组插入
  - 势能函数：$\Phi(D) = 2 \times \text{size} - \text{capacity}$
  - 插入时：
    - 不扩容：实际 $c_i=1$，$\Delta\Phi = 2$，平摊 $c_i'=3$
    - 扩容：实际 $c_i=k+1$，$\Delta\Phi = 2-k$，平摊 $c_i'=3$

## 经典应用实例

### 1. 动态数组（栈/向量）
- **操作**：push/append
- **扩容策略**：容量翻倍（geometric expansion）
- **平摊分析**：$n$ 次插入平摊 $O(1)$
- **直观理解**：扩容频率指数减少（1,2,4,8,...）

### 2. 二进制计数器递增
- **问题**：$k$ 位二进制计数器从 0 开始递增
- **观察**：每次递增翻转的位数不同
- **分析**：
  - 第 0 位每次翻转：$n$ 次
  - 第 1 位每 2 次翻转：$n/2$ 次
  - 第 2 位每 4 次翻转：$n/4$ 次
  - ...
  - 总翻转次数：$n + n/2 + n/4 + ... < 2n$
  - 平摊成本：$O(1)$

### 3. 并查集（带路径压缩+按秩合并）
- **操作**：m 次 union/find
- **平摊成本**：$O(\alpha(n))$（反阿克曼函数，增长极慢）
- $\alpha(n)$ 可视为常数（对于所有实际 n，$\alpha(n) ≤ 4$）

### 4. 伸展树（Splay Tree）操作
- **平摊成本**：$O(\log n)$
- 使用势能法分析，势能函数基于树的"熵"

## 三种方法对比表

| 方法 | 关键技巧 | 优点 | 缺点 | 适用场景 |
|------|----------|------|------|----------|
| **聚集分析** | 计算总成本均摊 | 直观简单 | 难以精确计算总成本 | 操作规律性强 |
| **记账法** | 提前收费存信用 | 直观，易解释 | 需要巧妙设计收费标准 | 操作间有明显"补贴"关系 |
| **势能法** | 定义势能函数 | 形式化强，灵活 | 需要设计合适的势能函数 | 复杂数据结构（伸展树、并查集） |

---

## 重要结论与公式

### 1. 平摊成本保证
对于任意长度为 $n$ 的操作序列：
$$
\sum_{i=1}^n c_i ≤ \sum_{i=1}^n c_i' = n \times \text{平摊成本}
$$
其中 $c_i$ 是实际成本，$c_i'$ 是平摊成本。

### 2. 动态数组扩容策略对比
| 扩容策略 | 平摊插入成本 | 空间利用率 |
|----------|--------------|------------|
| 固定增量（+k） | $O(n)$ | 高但不稳定 |
| 翻倍（×2） | $O(1)$ | 50%~100% |
| 黄金比例（×1.618） | $O(1)$ | 更平稳 |

### 3. 势能法通用公式
$$
c_i' = c_i + \Phi(D_i) - \Phi(D_{i-1})
$$
$$
\sum_{i=1}^n c_i' = \sum_{i=1}^n c_i + \Phi(D_n) - \Phi(D_0)
$$
因 $\Phi(D_n) ≥ 0$，$\Phi(D_0)=0$，有：
$$
\sum_{i=1}^n c_i ≤ \sum_{i=1}^n c_i'
$$

#### 邻接表适合稀疏图，邻接矩阵适合稠密图或需要快速判断边存在的场景。

## 单源最短路径算法

| 算法             | 时间复杂度          | 适用场景        |
| -------------- | -------------- | ----------- |
| Bellman-Ford   | O (VE)         | 含负权边，可检测负权环 |
| DAG 最短路径       | O (V+E)        | 有向无环图，可处理负权 |
| Dijkstra（优先队列） | O ((V+E) logV) | 无负权边，贪心策略   |

**关键**：
- Bellman-Ford：通用但慢，能处理负权
- DAG 最短路径：拓扑排序后线性时间
- Dijkstra：无负权时的最优选择

## 全源最短路径算法

| 算法 | 时间复杂度 | 适用场景 |
|------|------------|----------|
| Floyd-Warshall | O (V³) | 稠密图，代码简单，能处理负权（无负环） |
| Johnson（稀疏图） | O (VE + V²logV) | 稀疏图，结合 Bellman-Ford 和 Dijkstra |

**关键**：
- Floyd：适合 V 较小或需要频繁查询任意两点距离
- Johnson：稀疏图最优，先重赋权消除负权再用 Dijkstra

## 最大流算法

| 算法 | 时间复杂度 | 特点 |
|------|------------|------|
| Edmonds-Karp | O (VE²) | BFS 找增广路，实现简单 |
| Dinic | O (V²E) | 分层图+阻塞流，实际性能优秀 |

**关键**：
- Edmonds-Karp：基础算法，容易实现
- Dinic：竞赛常用，实际效率高，特别适合二分图最大匹配

# NP 完全性

## 四个关键类
- **P**：多项式时间可解
- **NP**：多项式时间可验证
- **NP-hard**：至少和 NP 中最难的问题一样难
- **NP-complete (NPC)**：既在 NP 中又是 NP-hard

## 核心关系
P ⊆ NP  
NPC = NP ∩ NP-hard  
若任一 NPC∈P，则 P = NP

## 证明 NPC 的两步法
1. 证明问题∈NP（可多项式验证）
2. 证明是 NP-hard（从已知 NPC 问题多项式归约）

## 关键定理
- Cook-Levin 定理：SAT 是第一个 NPC 问题
- 归约传递性：若 A≤ₚB 且 B≤ₚC，则 A≤ₚC

## 经典 NPC 问题（归约链）
SAT → 3-SAT → 顶点覆盖问题 → 哈密顿回路 → TSP（决策版）  
SAT → 子集和 → 背包问题（决策版）

其他：团问题、旅行商问题

## 常见误区
- NP≠指数时间问题（是指数时间可解）
- NPC 问题仍有算法，只是无多项式精确解
- 不同 NPC 问题常数因子差异大
